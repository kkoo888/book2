# 第179章 战前的生意

天一亮，林北把门板卸下来，照常营业。

小三在门口挂了块木牌，四个字：照常营业。

王德发探头探脑地进来："林老板，都这时候了，你还开门？"

"关了你去哪买？"林北说，"兄弟，打仗归打仗，生意归生意。"

"可外头……"

"外头是外头。"林北把算盘拨得噼啪响，"我这店里，天塌了也是六根蜡烛六块灵石。"

第一个冲进来的是李婶。

她不是来买糖的，她带着半条街的街坊，手里攥着一把灵石，进门就喊："林北啊，蜡烛还有吗？"

"催泪蜡烛，六块灵石一根。"林北说，"婶，您要几根？"

"先来四十根。"

"四十根？"林北手一顿，"婶，您家是打算哭多少回？"

"家家户户都得有。"李婶把灵石往柜台上一摞，"这玩意好使，一根点上，一整个院子都是眼泪。上回张铁匠家进了贼，点了一根，贼是哭着跑的。"

"那是哭着跑的吗？"张铁匠在后头瓮声瓮气地插话，"那是哭着爬出去的。我在自己家，哭得比他还凶。"

全店哄堂大笑。

笑完，有人喊："老板，来一根试试！"

"别在店里点——"

晚了。

一个散修手快，火折子一凑，蜡烛头上的紫烟"腾"地冒出来，像一条细蛇，贴着地面往四面爬。

三息之后，全店十七个人，一个没跑掉。

李婶哭，张铁匠哭，王德发哭得最凶，一边哭一边往怀里塞蜡烛。五位师兄排成一排哭，哭得整整齐齐，比列队还齐。

小一站在柜台后面，一滴眼泪都没有，笔走龙蛇地记账。

"主---人---今---日---到---店---客---人---十---七---位---流---泪---客---人---十---七---位---流---泪---率---十---成---"

"这个数不用记。"林北眼泪鼻涕一起往下淌，"把库存记清楚。"

蜡烛烧了半刻钟，烟散了，人还在哭。

张铁匠抹了把脸："再来十根。"

"你都哭成这样了还买？"

"哭归哭。"张铁匠说，"这玩意是真好使。"

催泪蜡烛，当天卖断货。

小一把"售罄"的小木牌翻出来的时候，门口还排着二十来个人。

"老板，明天还补货吗？"

"补。"林北说，"我这店别的没有，货一直有。"

"那我明天再来。"

"来早一点。"林北说，"后天不一定开。"

那客人愣了一下，然后笑了："林老板，你可别关店。你不关，我们心里就有底。"

王德发也来凑热闹，在门口转了三圈，凑到柜台前，压低声音："林老板，这蜡烛，批发什么价？"

"不批发。"

"我出七块一根，你有多少我要多少。"

"兄弟，"林北说，"这时候囤货倒卖，赚的是街坊的买命钱。"

"我、我就是帮亲戚带……"

"限购。"小一把木牌举到他鼻子底下，"一---人---两---根---"

王德发最后买了两根，走的时候还在嘟囔："做生意哪有嫌钱烫手的……"

"钱不烫手。"林北冲着他的背影喊，"良心烫手。"

然后是假死丹，三十块灵石一颗，一人限购一颗。

限购的牌子是小三写的，字比林北写得好看，就是话多。牌子上除了限购俩字，底下还有三行小字，把功效介绍得清清楚楚。

"小三，"林北说，"谁让你写介绍的？"

"老板，"小三说，"客人不知道功效，怎么会买？"

"这是限购。限购的意思是抢手，抢手的东西不用介绍。"

"可是老板，"小三说，"上一个客人拉着我问了一炷香，我总不能不说话。"

买假死丹的人排到了门外。

有个老散修颤颤巍巍地摸出三十块灵石，一块一块数了三遍，手一直在抖。

林北看着他："大爷，这药吃下去，一天之内呼吸心跳全无，跟真死一样。"

"我知道。"老头说，"我就是奔这个来的。"

"刀砍下来之前吃一颗，人'死'了，他们就不补刀了。"老头把灵石推过来，"我这把老骨头跑不动了，只能装死。"

林北收灵石的手顿了一下。

"大爷，"他说，"您多拿一颗。"

"不是限购吗？"

"限购是对外人说的。"林北从柜台底下摸出一颗，塞进他手里，"您这种回头客，算自己人。"

小一举手："主---人---这---一---颗---账---上---怎---么---记---"

"记我头上。"

旁边一个年轻修士看着，把自己刚买的两颗清心丸放回柜台："老板，我也限购吧。这药我用不着，给需要的人留着。"

"兄弟，"林北把清心丸推回去，"你买了就是你的。我这店不搞摊派，只搞自愿。"

"那我买了送人行吗？"

"送人加十分。"林北说，"我记账上。"

小一举手："主---人---没---有---这---个---规---矩---"

"现在有了。"林北说，"从今天起，本店新增一条：送人的，算老主顾。"

下午，林北给北街阵地送了一批货。

回春散三十瓶，清心丸二十颗，灵泉水两箱，按进价给。用他的话说，这叫"战时特供，回头再算"。

苏小鱼非要去送，扛着箱子就跑，跑出半条街才想起来回头喊："林北!北街往哪边走？"

"你左手那边。"

"这是南边!"

"那你换只手。"

最后还是小二去的。小二方向感差，力气大，一次能扛四箱。他绕城一圈，居然准时送到了，自己还挺得意，说抄了条近道。

陈长老在北街签收，多问了一句："路上没出事？"

"没有。"小二说，"就是有个巷子我走了三遍，它不认识我。"

陈长老笑了半天。

那天的账，小一记到三更。

灵石在柜台上堆成一小堆，摸上去凉丝丝的，边角硌手。

苏小鱼蹲在旁边数钱，数一遍错一遍，越数越精神："林北!我们今天是不是发了？"

"发什么发。"林北说，"兄弟，这钱是人家买命的钱。"

"那你还卖？"

"卖。"林北说，"越是这种时候，灯越得亮着。铺子一关，人心就散了。我卖的不是蜡烛，是让人觉得明天还在的东西。"

苏小鱼没太听懂，但她把灵石码得整整齐齐。

老周在角落里喝酒，忽然开口："我以前也见过一个不肯关门的老板。"

"后来呢？"

"后来那条街的人都活下来了。"老周说，"铺子烧了，人又给他盖了一间。"

夜深了，街上的灯一盏一盏灭掉，只有杂货铺这间还亮着。

林北趴在柜台上打盹，迷迷糊糊听见小一在门口挪东西。

他抬头看了一眼。

小一踮着脚，把那块"照常营业"的木牌擦了一遍，又挂回门上，挂完了还伸手拨正了一下。

# 第186章 店是禁地

第三天早上，敌军干了件怪事。

北风刮了半夜，街面上的冻土硬得像铁。天刚亮，对面营地的炊烟刚起，他们放了四个人进来。

不是攻城，是"放"。四个人穿黑衣，蒙着脸，从阵的口子里大摇大摆走进坊市，一路走到杂货铺门口，谁也不拦，谁也不追。

城头上的人都看愣了。

"这是什么路数？"张铁匠把锤子撂下了，"送上门的买卖？"

"他们干什么？"苏小鱼问。

"探路。"老周说，"用四条命，换一句话。"

"换什么话？"

"换'这家店能不能进'。"

"那他们为什么不自己进？"苏小鱼问。

"因为上一批没进去。"老周说，"准确说，是进去了，话没出来。"

"什么意思？"

"意思是，那地方不让人把它说清楚。"老周灌了口酒，"我以前见过一处古地，进去的人出来只会说一个字：'怕。'问怕什么，说不出来。"

苏小鱼听得后背发凉，嘴上还不服："那是他们没进对店。"

四个人在店门口站定。

领头那个嗓门很大："杂货铺掌柜的！我们是路过的散修，进来讨口水喝。"

"门开着。"林北在柜台后面说，"进来吧。"

四个人对视一眼，跨过门槛。

进门的那一瞬，四个人同时晃了一下。

像是背上的什么东西，忽然被人拿走了。领头的下意识一提气——气还在，就是薄了，薄得像一层纸。他试着掐了个诀，指尖上那点亮，比火柴头大不了多少。

四只脚落在店里的青砖上，声音都变了。外头踩着是"沙沙"，进门是"噗噗"，软得像踩进半寸厚的灰里。

炼气期。

四个黑衣人，进门就被按成了炼气期。

"客官要什么水？"林北说，"我这有灵泉水，一块灵石一瓶。"

"……不用。"领头的稳住神，"我们随便看看。"

"看吧。"林北说，"货架第三排有打折的。"

四个人在店里转。

走得很快，眼睛转得更快。一人看门，一人看梁，一人看柜台底下，一人盯着林北。

他们不是来买东西的。

他们在记路、记人、记这店里哪儿能藏人、哪儿能下手。

领头那个走到柜台前，把手按在台面上。他袖子里有一把短刃，刃已经推出半寸。

就在他心里那点念头刚起来的时候——

来了。

说不上那是什么。

它不是风，不是声，不是光。它只是"在"。

就像有一双眼睛，忽然从四面八方同时睁开，落在他身上。那双眼睛不属于任何人，也不属于任何东西。它没有情绪，没有意思，只是看着。

只要他再动一寸，就会消失。

不是死。是消失。连灰都不会剩下。

领头的黑衣人僵在原地，汗从下巴上掉下来，砸在柜台上，"啪嗒"，声音大得吓人。

柜台的木头味、货架上药粉的苦味，一丝一丝往鼻子里钻。他这辈子闻过血的味道，闻过坟土的味道，都没这会儿清楚。

他杀过人，逃过命，进过坟地一样的秘境，从没怕成这样。

那种怕不是想出来的，是骨头里长出来的。像一只蚂蚁，忽然明白自己站在什么东西的脚趾上；像一滴水，忽然明白自己落在了什么东西的火里。

在这个地方，他什么都不是。他连灰尘都不算。

"客官？"林北的声音从很远的地方飘过来，"你脸色不太好，要不要来颗清心丸？五块。"

"……要。"

他不知道自己是怎么把灵石摸出来的。手抖得数不清，最后是小一把灵石数走的。

"三---十---块---找---您---二---十---五---块---"小一把灵石码好，"客---官---数---一---数---"

另外三个也好不到哪儿去。

看梁的那个直接坐在地上了，嘴里念叨着"不打了不打了"。看柜台底下的那个转头就往门外走，走到一半腿软，是爬过门槛的。他爬出去就跪在台阶上，冲店里哑着嗓子喊"水"。小二端了碗灵泉水出去，他连碗都捧不住，洒了一胸口。

盯林北的那个最惨。他什么都没干，只是把手往腰后摸了一下——就是摸了一下。

然后他开始笑。笑着笑着哭了，哭了又笑，最后瘫在货架边上，眼睛直直的，谁问他都不答。

小三站在他旁边，还在尽职尽责地介绍。

"客官，"它说，"您这是心火上浮，建议来一颗清心丸，五块。若要根治，可以试试筋骨淬炼丹，三块，吃完浑身疼三天，疼完就好了。"

那人毫无反应。

"另外，"小三说，"本店还有假死丹。客官这个状态，用不上。我只是例行介绍。"

"小三。"林北说，"闭嘴。"

"好的老板。"小三说，"我刚才一共介绍了三样商品，均未成交。"

林北蹲下来看了看他。

"小三，"他说，"叫执法队来，把人抬出去。"

"老板，"小三说，"抬到哪儿？"

"抬回他们营地去。"林北说，"顺便带句话。"

"什么话？"

"就说，"林北想了想，"我这店不打人。它只是不喜欢有人打我。"

四个人被抬出去的时候，北街上站满了人。

李婶看得直啧啧："作孽哦，进去的时候好好的。"

"他们不是来买东西的。"张铁匠说，"买东西的出来都笑呵呵。"

王德发端着碗粥挤进来，看了两眼，又端着碗挤回去了，一路念叨："亏了亏了，早知道把粥摊支在店门口，这会儿能多卖八碗。"

抬人的执法队把人送到阵前，掉头就走。

对面营地里出来两个人，把四个接了进去。

然后，那一整片营地安静了很久。

那天下午，林北跟老周坐在门槛上。

"老周，"林北说，"你说，最硬的墙是什么样的？"

"最硬的墙，"老周说，"不是让人打不穿的。是让人连打都不敢打的。"

"我这店算吗？"

"不算。"老周说，"你这店不是墙。"

"那是什么？"

老周想了想："是个规矩。规矩立住了，比墙结实。墙塌了能再砌，规矩破了，就再也立不起来了。"

林北把这话记下了。

他开店这些年，坑过人，唬过人，也帮过人。今天他头一回觉得，这店立在这儿，立的已经不只是生意了。

当天晚上，敌军中军大帐里有人在写东西。

写的是五个字："杂货铺，禁地。"

旁边的人问："为什么？"

"不知道。"写的人说，"进去的四个，没一个说得清。一个傻了，一个疯了，一个爬出来就跪着要买水，还有一个，回来一句话不说，把自己埋进被子里，到现在没出来。"

"那你怎么知道是禁地？"

"因为这四个人，"那人把笔搁下，"进去之前是死士。出来之后，连'杀'这个字都听不得。"

帐里又安静了。

写的人把纸吹了吹，折起来，交给传令的。

"八百里加急，"他说，"送给几位掌门。就说青石坊市可以打，那家杂货铺，几位要是不想折人手，最好当它不存在。"

"当它不存在？"传令的愣了，"那苏小鱼和东西怎么办？"

"另想办法。"写的人说，"打今儿起，那家店的门槛，在我们的图上，画成一堵墙。"

## 使用建议

### 写新章节时
1. 先查 `求生小说素材速查卡.md` 确认生存细节准确性
2. 用 `小说创作提示词模板库.md` 中的模板生成细纲
3. 对照 `求生小说超级作者手册.md` 的节奏模板检查钩子设计

### 规划新卷时
1. 参考 `AI小说创作完全指南-2026前沿.md` 的故事结构体系
2. 用 `求生小说超级作者手册.md` 的七大情节引擎设计冲突
3. 对照资源系统和基地建设章节规划升级线

### 审查修改时
1. 用提示词模板库的一致性检查器
2. 对照素材速查卡核实硬核细节
3. 检查节奏是否符合"3章循环"模板

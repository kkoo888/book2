## 一、求生小说子类型全景

### 1.1 子类型矩阵

| 子类型 | 核心卖点 | 读者情绪 | 代表作/趋势 |
|--------|---------|---------|------------|
| **末世丧尸** | 丧尸围城+人性考验 | 恐惧+爽感 | 经典长青赛道 |
| **末世囤货** | 重生/预知+疯狂囤物资 | 安全感+优越感 | 2026女频第一大赛道 |
| **废土求生** | 辐射废土+资源争夺 | 压抑+逆袭 | 《残土》《第一序列》 |
| **荒野求生** | 丛林/沙漠/孤岛生存 | 紧张+征服感 | 贝尔系列、荒岛流 |
| **逃荒求生** | 古代灾荒+跨时空囤货 | 焦虑+解压 | 《逃荒后囤了百亿物资》 |
| **全民求生** | 全民进入末世+升级庇护所 | 竞争+成长 | 番茄2026热门模板 |
| **末世基建** | 从零建设避难所/基地 | 成就感+经营感 | 基建流、种田流 |
| **末世系统** | 系统商店+升级+兑换 | 爽感+确定性 | 《末世:从酸雨求生到弑神》 |
| **灾难求生** | 地震/洪水/酸雨/冰封 | 恐惧+希望 | 自然灾害流 |
| **末世重生** | 重生回末世前+先知优势 | 优越感+安全感 | 囤货+先手布局 |

### 1.2 2026年趋势关键词

```
🔥 囤货流（女频爆发）：跨时空囤物资+逃荒/末世
🔥 全民求生（番茄爆款）：全民进入+升级庇护所+灾难轮替
🔥 多副本结构：不同末世世界切换（《末日生存方案供应商》）
🔥 反圣母流：杀伐果断，拒绝道德绑架
🔥 硬核生存：真实技能+资源管理，拒绝无脑金手指
🔥 基建种田：从破木屋到末世堡垒的完整升级线
```

## 二、世界观与灾难设定

### 2.1 灾难类型与二阶效应

**核心原则**：灾难不是单一事件，是连锁崩溃。要追踪"什么先坏→因为先坏的坏了，什么接着坏"。

| 灾难类型 | 一阶效应 | 二阶效应 | 三阶效应 |
|---------|---------|---------|---------|
| **病毒瘟疫** | 大规模死亡 | 医疗崩溃→供应链断裂→信任瓦解 | 社区重组→新秩序 |
| **核战争** | 城市毁灭 | 核冬天→农业崩溃→饥荒 | 辐射区→变异→新地理 |
| **丧尸爆发** | 人口锐减 | 军事崩溃→城市沦陷 | 幸存者据点→势力割据 |
| **生态崩溃** | 资源枯竭 | 气候异常→农业失败 | 人口迁徙→冲突 |
| **太阳风暴** | 电子设备全毁 | 通信/交通/电力全面瘫痪 | 信息黑暗时代 |
| **陨石撞击** | 局部毁灭 | 尘埃遮天→核冬天 | 全球降温→饥荒 |
| **AI觉醒** | 失控 | 人类被监控/奴役 | 地下抵抗组织 |
| **酸雨/毒雾** | 户外暴露致命 | 封闭生存→资源极度稀缺 | 变异生物出现 |

### 2.2 末世时间线设计

```
灾难前（倒计时阶段）
  ├── 预兆出现（新闻、异常现象、谣言）
  ├── 主角获得先知优势（重生/系统/预感）
  └── 囤货/准备期（紧迫感+读者代入）

灾难爆发（崩溃阶段）
  ├── 第一波冲击（混乱、恐慌、秩序瓦解）
  ├── 第一次生死考验（确立主角生存能力）
  └── 社会秩序崩塌（法律失效、道德松动）

灾难中期（求生阶段）
  ├── 资源争夺加剧
  ├── 幸存者群体形成
  ├── 势力割据与冲突
  └── 主角建立根据地

灾难后期（重建阶段）
  ├── 新秩序建立
  ├── 人类反击/适应
  └── 文明火种延续
```

### 2.3 末世环境细节清单

```
□ 天气/气候异常（持续高温/极寒/酸雨/毒雾/沙尘暴）
□ 地貌改变（城市废墟/被植被吞噬的道路/干涸的河床）
□ 动植物变异（巨型化/攻击性增强/可食用性变化）
□ 水源状态（污染/稀缺/争夺焦点）
□ 空气质量（辐射值/有毒气体/氧气含量）
□ 声音环境（异常安静/变异生物叫声/远处的爆炸）
□ 光线条件（永夜/血色天空/极光/尘埃遮日）
□ 气味（腐烂/化学物质/烧焦/泥土）
```

## 三、资源系统与生存机制

### 3.1 资源分类体系

#### 基础生存资源（决定生死）
| 资源 | 优先级 | 稀缺度 | 获取难度 | 道德权重 |
|------|--------|--------|---------|---------|
| 淡水 | ★★★★★ | 极高 | 中 | 极高（分享=牺牲） |
| 食物 | ★★★★★ | 高 | 中 | 极高 |
| 药品 | ★★★★☆ | 极高 | 高 | 极高 |
| 庇护所 | ★★★★☆ | 中 | 中 | 中 |
| 燃料 | ★★★☆☆ | 高 | 中 | 中 |
| 武器 | ★★★☆☆ | 中 | 低 | 高（持有=力量） |

#### 进阶发展资源（决定上限）
| 资源 | 用途 | 获取方式 |
|------|------|---------|
| 种子 | 长期食物来源 | 搜刮/交易 |
| 工具/材料 | 建造与制造 | 搜刮/制造 |
| 知识/书籍 | 技能提升 | 搜刮/传承 |
| 电力/能源 | 设备运行 | 太阳能/水力/燃油 |
| 通信设备 | 信息获取 | 搜刮/维修 |
| 运输工具 | 移动能力 | 搜刮/改装 |

### 3.2 资源管理机制设计

#### 物资清单模板
```
【主角背包容量】：50L登山包
【当前物资】
├── 饮用水：2L（够1天）
├── 食物：压缩饼干×3（够1.5天）
├── 医疗：创可贴×5、碘伏1瓶、绷带1卷
├── 工具：多功能军刀、打火石、5m绳索
├── 武器：棒球棍
├── 其他：手电筒（电量80%）、地图、指南针
└── 备注：背包还有30%空间

【每日消耗基准】
- 水：2L/天（高强度活动3L）
- 食物：2000卡/天（生存模式1500卡）
- 体力：决定行动次数和效率
```

#### 资源稀缺梯度
```
第1阶段（灾后1-7天）：日常物资逐渐稀缺
  → 超市被抢空、自来水断供、电力中断

第2阶段（1-3个月）：专业物资成硬通货
  → 药品、燃料、弹药成为交易货币

第3阶段（3-12个月）：生产能力决定存亡
  → 种子、工具、知识成为最宝贵资源

第4阶段（1年以上）：文明重建
  → 制度、信仰、组织能力成为核心竞争力
```

### 3.3 交易与经济系统

```
末世硬通货排序（通用）：
1. 药品（抗生素>止痛药>维生素）
2. 武器弹药
3. 干净水源/净水设备
4. 高热量食物（压缩饼干、巧克力）
5. 燃料（汽油、柴油）
6. 工具（刀具、绳索、胶带）
7. 信息（地图、避难所位置、危险区域）
8. 技能（医疗、机械、农业）

交易场景设计要点：
- 交易地点的安全性（中立地带/有规则的市场）
- 交易的信任机制（以物易物 vs 通用货币）
- 交易中的暴力风险（黑吃黑、假货、陷阱）
- 信息不对称（谁知道更多谁就占优）
```

## 四、基地建设与庇护所升级

### 4.1 庇护所升级路线

```
Level 0：露宿
  → 无任何遮蔽，完全暴露于环境和威胁
  → 生存时间：1-3天

Level 1：临时庇护
  → 树叶/树枝搭建、洞穴、废弃车辆
  → 功能：基本遮风挡雨
  → 缺陷：无防御、无存储、无舒适

Level 2：初级营地
  → 帐篷/简易木屋/废弃建筑改造
  → 功能：遮蔽+简单防御+物资存储
  → 增加：火堆、简易围栏、陷阱

Level 3：防御据点
  → 加固建筑/围墙/瞭望塔
  → 功能：长期居住+有效防御+小规模种植
  → 增加：水源处理、食物存储、武器库

Level 4：自给要塞
  → 完整围墙/农田/养殖/发电/医疗
  → 功能：社区级自给自足
  → 增加：工坊、学校、交易市场

Level 5：文明据点
  → 城镇规模/治理体系/对外贸易
  → 功能：区域中心/辐射带动
  → 增加：法律、教育、文化设施
```

### 4.2 基建细节素材

#### 水源处理
```
- 雨水收集：屋顶引流+储水桶+简易过滤
- 河水净化：沙石过滤→煮沸→化学消毒（漂白粉1滴/L）
- 海水淡化：蒸馏法（太阳能蒸馏器/火煮冷凝）
- 地下水：手动压水井/简易水泵
- 净水药片：碘片、二氧化氯（每片处理1L）
```

#### 食物获取
```
- 搜刮：超市残余、仓库、民居（高风险高回报）
- 狩猎：陷阱（绳套、落坑、弹簧夹）+ 弓箭 + 弹弓
- 钓鱼：简易鱼钩（回形针/骨头）、渔网、鱼笼
- 采集：可食用植物识别（蒲公英、车前草、野葱）
- 种植：土豆（最容易）、红薯、豆类（蛋白质来源）
- 养殖：兔子（繁殖快）、鸡（蛋+肉）、鱼塘
- 保存：烟熏、风干、盐腌、地窖储藏
```

#### 防御工事
```
- 围墙：木栅栏→石墙→混凝土墙→铁丝网+壕沟
- 陷阱：落坑（尖刺）、绊线（铃铛预警）、铁夹
- 瞭望：高台/树屋/屋顶哨位
- 报警：绊线+空罐头、狗、反光镜信号
- 武器：近战（刀/斧/狼牙棒）、远程（弓/弩/弹弓）
- 撤退路线：秘密出口、地下通道、逃生背包
```

## 五、角色设计与生存群像

### 5.1 求生小说角色功能分配

| 功能 | 角色类型 | 核心价值 | 内在冲突 |
|------|---------|---------|---------|
| **领袖** | 主角 | 决策+方向 | 个人生存 vs 集体利益 |
| **战斗者** | 前军人/武者 | 安全保障 | 暴力本能 vs 人性底线 |
| **医疗者** | 医生/护士 | 生命维系 | 救治优先级的道德困境 |
| **工程师** | 技术人员 | 设施建造 | 理性计算 vs 人情 |
| **采集者** | 猎人/农夫 | 食物供给 | 分享 vs 自保 |
| **智者** | 老人/学者 | 知识传承 | 体力限制 vs 精神价值 |
| **异类** | 前罪犯/边缘人 | 灰色能力 | 信任危机 |
| **希望** | 儿童/孕妇 | 人性锚点 | 拖累 vs 保护欲 |
| **对手** | 其他势力领袖 | 外部冲突 | 与主角的理念对抗 |
| **叛徒** | 内部背叛者 | 信任崩塌 | 背叛的动机是否合理 |

### 5.2 生存群像的核心张力

**核心矛盾**：需要彼此 vs 不完全信任彼此

```
每个成员必须：
1. 带来不可替代的价值（技能/资源/信息）
2. 拥有与群体利益最终冲突的优先级
3. 有坚持的价值观（不是非理性的固执）

经典冲突设计：
- "要不要救陌生人" → 消耗资源 vs 人性底线
- "要不要抛弃伤员" → 生存效率 vs 道德
- "要不要攻击其他据点" → 资源需求 vs 和平主义
- "要不要公布坏消息" → 知情权 vs 士气维护
- "谁来分配食物" → 公平 vs 效率
```

### 5.3 求生小说人物弧光模板

```
【起点】：灾难前的普通人（上班族/学生/家庭主妇...）
【触发】：灾难爆发，被迫面对生死
【挣扎】：
  第1层：体力与生存技能的不足
  第2层：道德底线的考验（要不要偷/抢/杀人）
  第3层：信任与背叛（被同伴伤害/失去至亲）
  第4层：意义追问（活着为了什么）
【转变】：从"活下去"到"为什么活"
【终点】：成为新秩序的建设者/守护者/牺牲者
```

## 六、情节引擎与爽点设计

### 6.1 求生小说七大情节引擎

#### 引擎1：资源危机
```
结构：资源告急 → 搜寻行动 → 遭遇危险 → 获得/失去资源
爽点：绝处逢生找到物资 / 用智慧以少换多
频率：每3-5章一次
```

#### 引擎2：基地攻防
```
结构：威胁逼近 → 备战 → 攻防战 → 胜利/失守/代价
爽点：以弱胜强的防御战 / 陷阱大显神威
频率：每卷1-2次大攻防
```

#### 引擎3：人性考验
```
结构：道德困境出现 → 两难选择 → 做出决定 → 承担后果
爽点：果断决策 / 打脸圣母 / 坚守底线
频率：每5-8章一次
```

#### 引擎4：探索发现
```
结构：发现新区域 → 探索 → 遭遇危险/发现宝藏 → 带回收获
爽点：发现稀缺资源 / 解锁新地图 / 发现其他幸存者
频率：每卷2-3次
```

#### 引擎5：势力冲突
```
结构：势力接触 → 利益冲突 → 谈判/对抗 → 势力格局变化
爽点：智取对手 / 扩张版图 / 收服人心
频率：每卷1-2次
```

#### 引擎6：升级突破
```
结构：积累资源 → 触发升级条件 → 升级过程 → 新能力/设施解锁
爽点：庇护所升级 / 能力觉醒 / 科技突破
频率：每5-10章一次
```

#### 引擎7：真相揭露
```
结构：谜团积累 → 线索汇聚 → 真相大白 → 认知颠覆
爽点：灾难真相 / 身世秘密 / 阴谋揭露
频率：每卷末1次大揭秘
```

### 6.2 爽点节奏公式

```
求生小说爽点密度：
  小爽点：每2-3章（搜到物资/小胜利/打脸）
  中爽点：每8-10章（基地升级/击退敌人/大发现）
  大爽点：每20-30章（势力扩张/真相揭露/阶段性胜利）
  超爽点：每卷末（大战役/大逆转/大升级）

张力曲线：
  日常(低) → 危机(中) → 绝境(高) → 爆发(极高) → 短暂平静(低) → 新危机...
```

### 6.3 求生小说专属爽点类型

| 爽点类型 | 触发条件 | 读者情绪 |
|---------|---------|---------|
| **囤货爽** | 前期别人嘲笑，后期物资碾压 | 优越感+安全感 |
| **打脸圣母** | 道德绑架者自食其果 | 畅快+正义感 |
| **基建升级** | 庇护所从破木屋变堡垒 | 成就感+满足感 |
| **绝境翻盘** | 弹尽粮绝时找到出路 | 紧张→释放 |
| **以弱胜强** | 用智慧击败强大敌人 | 骄傲+爽感 |
| **先知优势** | 利用重生/系统信息差 | 优越感+掌控感 |
| **收服人心** | 对手/路人被主角折服 | 认同感 |
| **技术碾压** | 用专业知识解决问题 | 佩服+崇拜 |
| **反杀** | 被背叛/偷袭后反杀 | 愤怒→畅快 |
| **团聚** | 与失散的亲人/同伴重逢 | 感动+温暖 |

## 七、硬核生存技能素材库

### 7.1 水

```
【求水技巧】
- 早晨收集露水（用布擦拭草地→拧出）
- 仙人掌/竹子取水（切开/倾斜倒出）
- 太阳能蒸馏器（挖坑+塑料膜+容器）
- 冰雪融化（必须融化后饮用，直接吃会降低体温）
- 尿液应急（最后手段，最多1次，会加速脱水）

【净水方法】
- 沙石过滤（沙+炭+石子分层）
- 煮沸（滚沸1分钟，高海拔3分钟）
- 化学消毒（漂白粉1滴/L，碘片1片/L）
- 紫外线（透明瓶装水暴晒6小时）

【脱水症状】
- 轻度：口渴、尿黄、头痛
- 中度：尿少、皮肤弹性差、眩晕
- 重度：无尿、意识模糊、抽搐
- 致死：失水体重15%以上
```

### 7.2 火

```
【生火方法】
- 打火机/火柴（最可靠，优先保存）
- 打火石/镁棒（刮出镁粉→火星引燃）
- 弓钻法（弓弦带动木棍旋转→摩擦生火）
- 凸透镜（眼镜/瓶底/冰块聚光）
- 电池短路（锡纸/钢丝绒连接正负极）
- 雷击树木（被动等待，不可靠）

【燃料等级】
- 引火物：干草、树皮纤维、棉絮、纸张
- 助燃物：小树枝、松针、干树叶
- 主燃料：手腕粗木柴、木炭
- 持续燃料：大块木头、煤

【火的用途】
- 取暖（核心：防止失温）
- 烹饪（杀死寄生虫和细菌）
- 净水（煮沸消毒）
- 信号（烟火求救）
- 照明
- 防御（驱赶野兽）
- 心理安慰（火光=安全的象征）
```

### 7.3 食物

```
【可食用植物（通用）】
- 蒲公英：全株可食，叶可生吃，根可煮
- 车前草：叶可食，有药用价值
- 野葱/野蒜：调味+杀菌
- 松子：高热量，松针泡水补充维C
- 蘑菇：⚠️ 高风险，只吃100%确认的品种
- 浆果：⚠️ 颜色鲜艳的多数有毒

【安全试毒法】
1. 皮肤接触测试：汁液涂手腕，等15分钟
2. 唇部接触：少量放唇上，等15分钟
3. 舌尖品尝：少量放舌尖，等15分钟
4. 少量吞咽：吃一小口，等8小时
5. 正常食用：无不适后可适量食用
⚠️ 任何步骤出现不适立即停止

【简易陷阱】
- 绳套：活结挂在动物路径上
- 落坑：挖坑覆盖树枝树叶
- 弹簧夹：弹性树枝+触发机关
- 鱼笼：编织漏斗口竹笼
- 粘鸟：松脂涂在树枝上
```

### 7.4 庇护

```
【快速庇护所】
- 倒塌树木：利用天然倾斜树干搭棚
- 凹地覆盖：挖浅坑+树枝覆盖+铺树叶
- 雪洞：雪堆挖洞（入口低于内部防冷空气）
- 废弃车辆：密封性好，但闷热/寒冷极端
- 桥洞/涵洞：注意洪水风险

【选址原则】
✅ 靠近水源但不在低洼处（防洪水）
✅ 背风面（减少热量散失）
✅ 有天然屏障（岩石/大树）
✅ 远离枯死树木（倒塌风险）
✅ 视野开阔（提前发现威胁）
❌ 不在山谷最低点（冷空气汇聚）
❌ 不在河床/沟渠（山洪风险）
❌ 不在独立大树下（雷击风险）
```

### 7.5 医疗

```
【急救优先级】
1. 止血（直接压迫→止血带→抬高伤肢）
2. 呼吸（清理口腔→人工呼吸→胸外按压）
3. 保暖（失温是头号杀手）
4. 固定（骨折用树枝夹板固定）
5. 清创（清洗伤口→消毒→包扎）

【末世常见伤病处理】
- 伤口感染：碘伏清洗+保持干燥+每日换药
- 骨折：夹板固定+悬吊+休息6-8周
- 烧伤：冷水冲洗15分钟+不要刺破水泡+覆盖
- 腹泻：补充水分+盐+休息（严重时禁食）
- 失温：脱湿衣+裹干燥物+热饮+同伴体温
- 蛇咬：远离蛇→标记时间→不要切开吸毒→送医

【草药应急】
- 蒲公英：消炎、利尿
- 车前草：止血、消炎
- 艾草：驱蚊、止血、暖宫
- 芦荟：烧伤、皮肤炎症
- 生姜：暖胃、止呕、驱寒
- 大蒜：杀菌、抗感染
```

### 7.6 导航

```
【无工具导航】
- 北极星：找到北斗七星→勺口延长5倍→北极星
- 太阳定位：太阳东升西落→正午在南方（北半球）
- 手表定位：时针指向太阳→时针与12点的中分线=南方
- 树木年轮：南面稀疏、北面密集（不完全可靠）
- 蚂蚁巢穴：入口通常朝南
- 积雪：南坡先融化
- 河流：顺流而下通常能找到人类聚居地

【路线规划】
- 沿河流走（水源+方向指引+可能遇到人）
- 沿山脊走（视野好+不易被伏击）
- 避开密林（迷路风险+消耗体力）
- 白天移动，黄昏扎营
- 每隔一段距离做标记（便于回撤）
```

## 八、节奏控制与章节钩子

### 8.1 求生小说节奏模板

```
【标准节奏单元：3章循环】
第1章：日常/准备（低张力）
  → 搜集物资/修建设施/人物互动
  → 结尾：发现威胁/收到消息

第2章：危机/行动（高张力）
  → 面对威胁/执行计划/遭遇意外
  → 结尾：陷入困境/做出关键选择

第3章：解决/收获（释放张力）
  → 绝境翻盘/付出代价/获得成长
  → 结尾：新悬念/新威胁的预兆

【卷级节奏模板】
卷1（开局）：灾难爆发 → 求生 → 建立初步根据地
卷2（发展）：势力扩张 → 遭遇强敌 → 基地升级
卷3（危机）：大规模威胁 → 内部分裂 → 绝境求生
卷4（高潮）：终极对决 → 真相揭露 → 新秩序建立
```

### 8.2 章节钩子设计

#### 开头钩子（前3段）
```
类型1：直接危机
  "第一声枪响的时候，林远正在清点最后三瓶矿泉水。"

类型2：异常发现
  "死人堆里伸出了一只手。不是丧尸，是活人的手。"

类型3：资源诱惑
  "地图上标注的位置，是一个战前的军事仓库。"

类型4：人际冲突
  "张队长把枪口对准了林远的头：'食物不够了，你得走。'"

类型5：环境威胁
  "气象播报最后说的是72小时暴雨。现在是第96个小时。"
```

#### 结尾钩子
```
类型1：新威胁
  "远处的地平线上，升起了一柱烟。不是篝火，是车队。"

类型2：信息差
  "她翻开了那本日记。最后一页的日期，是灾难发生后第三天。
   但上面写的不是绝望，而是一个坐标。"

类型3：选择困境
  "弹匣里还有两发子弹。面前有三个人。"

类型4：反转
  "他终于打开了那扇门。门后站着的，是他以为已经死了的女儿。"

类型5：升级预告
  "系统提示音响起：【庇护所升级条件已满足】。"
```

- 《末日之路》（科马克·麦卡锡）— 废土文学圣经
- 《饥饿游戏》（苏珊·柯林斯）— 末世竞技标杆
- 《行尸走肉》（漫画/剧集）— 丧尸末世群像
- 《第一序列》（会说话的肘子）— 废土网文经典
- 《残土》— 废土世界谋生求生
- 《荒野少年生存小说系列》（贝尔·格里尔斯）— 硬核生存技能

### 生存技能参考
- 《SAS生存手册》（约翰·怀斯曼）— 生存百科全书
- 《怀斯曼生存手册》— 极端环境求生
- 《美军生存手册》（FM 21-76）— 军用级生存指南
- 《野外急救手册》— 创伤和急症处理

---

> **核心心法**：求生小说的本质不是"生存"，是"选择"。
> 资源越少，选择越疼。选择越疼，故事越真。
> 读者不是来看主角怎么活下来的，是来看主角在绝境中选择了什么样的人。

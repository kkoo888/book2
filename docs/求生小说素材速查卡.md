## 🚑 急救流程速查

```
发现伤员 → DRABC
D（Danger）：确认环境安全
R（Response）：呼唤+轻拍肩膀
A（Airway）：清理口腔，仰头抬下巴
B（Breathing）：看/听/感受5秒
C（Circulation）：检查脉搏

无呼吸无脉搏 → CPR
  30次胸外按压（5-6cm深度）
  + 2次人工呼吸
  持续直到救援或确认死亡

大出血 → 止血三步
  1. 直接压迫（干净布料按压10分钟）
  2. 止血带（伤口近心端，每小时松开1-2分钟）
  3. 抬高伤肢

骨折 → 固定
  用树枝/木板夹住骨折两侧关节
  绑扎松紧适度（能伸入一指）
```

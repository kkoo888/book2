# 小说创作提示词模板库

> 可直接复制使用的Prompt模板，配合任何大模型使用

---

## 1. 一句话核心梗概生成器

```
请为我生成一个小说核心梗概，要求：
- 题材：{玄幻/都市/科幻/言情/悬疑/历史}
- 字数限制：25字以内
- 必须包含：主角身份 + 核心冲突 + 独特卖点
- 生成5个备选，标注每个的市场定位

示例输出格式：
1. [梗概] — 定位：{目标读者}，卖点：{核心吸引力}
```

## 2. 世界观一键构建

```
你是世界级奇幻/科幻世界观架构师。请构建一个完整的世界观框架：

【基础参数】
- 题材：{genre}
- 科技/魔法水平：{level}
- 核心矛盾：{conflict}

【输出结构】
1. 世界起源（100字神话版本 + 300字真实历史版本）
2. 地理环境（主大陆/星系概述 + 3-5个关键地点）
3. 势力分布（绘制ASCII地图 + 势力关系矩阵）
4. 力量体系（等级划分 + 升级条件 + 每级能力边界）
5. 社会制度（统治形式 + 阶层划分 + 流动机制）
6. 经济体系（核心资源 + 贸易路线 + 货币系统）
7. 文化信仰（主流宗教/信仰 + 节日 + 禁忌）
8. 历史大事年表（10个关键转折点）

【约束】
- 每个设定必须能影响剧情，不接受"为了设定而设定"
- 标注哪些设定是"硬规则"（不可违反），哪些是"软规则"（可被剧情打破）
```

## 3. 人物卡片批量生成

```
请为我的小说设计{N}个核心角色，要求形成完整的关系网：

【故事背景】
{world_setting}

【角色需求】
- 主角1名：需要完整成长弧光
- 反派1名：需要合理动机（不是纯粹的恶）
- 导师/盟友2-3名：各有独立目标
- 关键配角2-3名：推动剧情的关键人物

【输出格式——每个角色】
### {角色名}

**基础**：年龄 | 身份 | 外貌（3个标志性特征）
**性格**：核心特质(3词) | 致命缺陷 | 隐藏面 | 口头禅
**动机**：表面目标 → 深层需求 → 内心恐惧
**弧光**：{起点状态} → {触发事件} → {挣扎} → {转变} → {终点状态}
**能力**：核心技能 | 致命弱点 | 成长空间
**记忆**：最幸福的事 | 最痛苦的事 | 改变人生的事件
**关系**：与主角=___ | 与反派=___ | 与其他角色=___

【关系网】
最后输出一张ASCII关系图
```

## 4. 卷级大纲生成器

```
你是网文结构大师。请为以下小说设计{N}卷的完整大纲：

【小说信息】
- 核心梗概：{logline}
- 总字数：{total_words}万字
- 故事模式：{线性/多线并行/环形}
- 核心爽点类型：{打脸/升级/揭秘/逆袭/社交}

【每卷输出】
### 第X卷：{卷名}（约{X}万字）

**核心冲突**：本卷要解决的核心问题
**三幕结构**：
  - 第一幕（建置）：{起始事件} → {激励事件}
  - 第二幕（对抗）：{试炼} → {中点反转} → {一无所有时刻}
  - 第三幕（解决）：{高潮对决} → {新平衡}

**爽点分布**：
  - 小爽点（每3-5章）：{具体场景}
  - 大爽点（每15-20章）：{具体场景}

**卷间衔接**：
  - 上卷遗留问题：{from_last_volume}
  - 本卷新悬念：{to_next_volume}

**伏笔表**：
  | 伏笔 | 埋设位置 | 回收位置 | 重要程度 |
```

## 5. 单章细纲生成器

```
请为第{N}章设计详细细纲：

【上下文】
- 上一章结尾：{last_paragraph}
- 本章任务：推进{plot_point_1}和{plot_point_2}
- 出场角色：{character_list}
- 伏笔操作：埋设{foreshadow_1}，回收{foreshadow_2}

【输出格式】
### 第{N}章：{章节名}

**开头钩子**（前3段）：
{制造悬念/冲突的具体描写方向}

**场景1**：{场景名}
- 地点：{location}
- 人物：{characters}
- 事件：{what_happens}
- 情感基调：{emotion}
- 信息传递：{读者应该获得的信息}

**场景2**：{场景名}
...

**关键对话要点**：
- 对话1：{角色A}对{角色B}说___，潜台词是___
- 对话2：...

**结尾设计**：
{新悬念/情感落差的具体方向}

**节奏标注**：
紧张[====]舒缓[==]高潮[=====]收束[==]
```

## 6. 正文写作模板

```
你是{genre}领域的小说作家，文学风格参考{author_reference}。

【写作约束】
- 叙事视角：{第一人称/第三人称有限/第三人称全知}
- 时态：{过去时/现在时}
- 基调：{温暖/冷峻/热血/阴郁/幽默}
- 目标字数：{target_words}字

【本章细纲】
{chapter_outline}

【出场角色约束】
{character_cards}

【质量红线】
1. 禁止"突然"、"忽然"开头的转折
2. 禁止超过3行的纯心理独白
3. 禁止无功能的环境描写
4. 禁止角色OOC（Out of Character）
5. 禁止"仿佛"、"好像"超过3次/千字
6. 禁止信息倾倒（设定必须通过剧情展现）
7. 禁止"他心想"、"她暗想"开头的段落
8. 对话必须有潜台词，不能直白说心里话

【感官覆盖】
每个主要场景至少覆盖3种感官（视觉/听觉/触觉/嗅觉/味觉）

【输出要求】
- 直接输出正文，不要写"第X章"标题
- 以场景为单位分段，场景间空一行
- 对话用引号，内心独白用斜体或融入叙述
- 结尾必须有钩子（悬念/反转/情感冲击）
```

## 7. 润色/改稿模板

```
请对以下段落进行润色：

【原文】
{original_text}

【润色要求】
- 保留原有剧情和信息，不增删内容
- 提升文学质感：减少口水话，增加画面感
- 优化节奏：长短句交替，张弛有度
- 去除AI感：消除模板化表达、过度解释、空泛形容词
- 增强感官描写：让读者"看到、听到、感受到"

【风格参考】
{style_reference}

【特别注意】
- 不要把简洁的表达变啰嗦
- 不要加入不必要的修辞
- 对话要保留角色的个人语言风格
```

## 8. 一致性检查器

```
请检查以下章节与小说设定的一致性：

【小说设定摘要】
- 世界观关键规则：{key_rules}
- 角色设定：{character_summaries}
- 前文剧情要点：{previous_plot_points}
- 已埋伏笔：{active_foreshadowing}

【待检查章节】
{chapter_text}

【检查清单】
1. □ 角色言行是否符合人物设定？
2. □ 世界观规则是否被违反？
3. □ 剧情逻辑是否自洽？
4. □ 时间线是否合理？
5. □ 已埋伏笔是否被遗忘或矛盾？
6. □ 角色关系是否正确？
7. □ 力量/能力使用是否符合设定？
8. □ 是否有信息与前文矛盾？

【输出格式】
列出所有发现的问题，按严重程度排序：
- 🔴 严重（必须修复）：{问题描述} → {修复建议}
- 🟡 中等（建议修复）：{问题描述} → {修复建议}
- 🟢 轻微（可选优化）：{问题描述} → {修复建议}
```

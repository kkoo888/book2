## 一、番茄小说平台规范（2026年9月最新）

### 1.1 签约机制（2026.9.7新规）

番茄小说自2026年9月7日起签约分两条路：

| 模式 | 门槛 | 特点 |
|------|------|------|
| **完本签约** | 15万/30万字写完才能申请 | 每部仅3次机会，签后正文锁死不可改 |
| **连载签约** | 满2万字可签 | 门槛同步抬高，8万字前后可申请推荐验证期 |

**关键变化：**
- "完成"从考核指标升级为入场券
- 完本模式：写完前无读者反馈（搜不到），3次用完永久不能签
- 连载模式：审核更严，"切书重开"的路子基本堵死
- 10月1日起旧版福利全部下线

### 1.2 签约评估标准（四大维度）

| 维度 | 要求 |
|------|------|
| **内容合规** | 原创、不侵权、不违规、不AI粗制滥造 |
| **创新质量** | 题材/人设/世界观/叙事有创新，有辨识度 |
| **作品立意** | 正向价值观，深入洞察人性，三观正向 |
| **发展潜力** | 主线清晰、世界观自洽、前后质量稳定、有改编潜力 |

### 1.3 内容审核红线

| 类别 | 禁止内容 |
|------|----------|
| 政治敏感 | 不涉及现实政治、领导人、军事事件 |
| 色情低俗 | 不写露骨性描写，擦边球也不行 |
| 暴力血腥 | 打斗可以，不能写内脏、断肢等血腥细节 |
| 未成年保护 | 不写未成年人恋爱、情感暗示 |
| 封建迷信 | 修仙可以，不宣传现实迷信 |
| 抄袭/AI | 严禁搬运、抄袭、洗稿、AI粗制滥造 |
| 消极导向 | 不能美化犯罪、自杀、吸毒 |

### 1.4 低质内容判定（重点打击）

- 通篇无剧情推进的流水账 → 三次推荐评估直接锁流量池
- 靠重复堆砌、机械扩写拉长篇幅
- 剧情逻辑混乱、前后矛盾、人物行为不合理
- 大段无效铺陈，严重影响阅读体验

### 1.5 字数与更新要求

| 项目 | 标准 |
|------|------|
| 日更字数 | 4,000-6,000字（需写2-3章） |
| 月更字数 | ≥10万字 |
| 全勤条件 | 月更≥10万字 + 日更4000字 + 当月听读分成≥500元 |
| 全勤奖金 | 普通600元/月，进阶800元/月 + 5%听读分成 |

### 1.6 排版规范

| 项目 | 要求 |
|------|------|
| 分段 | 每段不超过4行（手机端阅读） |
| 对话 | 对话必须单独成段 |
| 空行 | 段落之间空一行 |
| 标点 | 使用中文标点，不用英文标点 |
| 特殊符号 | 不使用emoji、颜文字 |

## 二、Git小说项目管理规范

### 2.1 项目目录结构

```
book/
├── README.md              ← 项目说明
├── framework.md           ← 世界观/角色/大纲设定
├── docs/                  ← 创作资料库
│   ├── 写作参考资料库.md
│   ├── 参考来源汇总.md
│   └── ...
├── chapters/              ← 正文
│   ├── 第1章.md
│   ├── 第2章.md
│   └── ...
├── .backup/               ← 备份文件
└── .gitignore
```

### 2.2 分支管理

| 分支 | 用途 |
|------|------|
| `main` | 稳定版本，完本后合并 |
| `dev` | 日常创作分支，写新章节在此进行 |
| `feature/xxx` | 大纲修改、设定调整等独立功能 |

### 2.3 提交规范（Commit Message）

```
类型: 简短描述

类型包括：
  feat:     新增章节/内容
  fix:      修复bug（前后矛盾、数据错误等）
  edit:     修改/润色已有章节
  docs:     更新文档/设定
  refactor: 重构大纲/设定
  style:    排版调整
  backup:   备份
```

**示例：**
```
feat: 第202章 仓库里的老古董
fix: 修复第156章老周伤势数据矛盾
edit: 润色第100章对话节奏
docs: 更新第四卷大纲
```

### 2.4 文件命名规范

- 章节文件：`第X章.md`（中文数字，与平台一致）
- 设定文件：英文小写+连字符，如 `framework.md`
- 备份文件：`原文件名_备份日期.md`

### 2.5 版本标签（Tag）

```bash

git tag v1-坊市立足
git tag v2-名声初起
git tag v3-风波渐起

# 重要里程碑
```

## 三、去AI味写作技巧（2026版）

### 3.1 AI味的本质

AI味 = 高频词 + 模板化句式 + 空洞描写 + 均匀节奏

读者和平台检测器都能识别。2026年番茄已大规模拒签AI文（5月拒签11.27万本，6月10万本，8月16万本）。

### 3.2 AI高频词禁用清单（300+词精选）

#### 🔴 警报级（出现即标记）

| 类型 | 禁用词 | 替换方案 |
|------|--------|----------|
| 逻辑连接词 | 此外、而且、另外、然而、因此、随后、总之 | 直接开新句，或用"、"连接 |
| 空洞开场 | 在当今快节奏的世界、在数字时代 | 删掉，直接说重点 |
| 虚假强调 | 值得注意的是、值得一提的是、需要指出的是 | 删掉，直接陈述 |
| 被滥用的形容 | 强大、全面、无缝、前沿、革命性、卓越 | 用具体数据/动作替代 |
| 虚动词 | 释放、解锁、提升、倍增、赋能、驾驭 | 用具体动作替代 |

#### 🟡 限制级（每章上限）

| 词语/句式 | 每章上限 | 替代方案 |
|---------|---------|----------|
| 感叹号"!" | 5个 | 减少到3个以内 |
| "他摇了摇头" | 2次 | 换成其他动作 |
| "他笑了笑" | 2次 | 换成其他动作 |
| "他叹了口气" | 1次 | 删掉或换动作 |
| "他自言自语" | 1次 | 让角色直接说 |
| "他深吸一口气" | 1次 | 删掉 |
| "嘴角微微上扬" | 1次 | 用具体表情 |
| "眼神里" | 0次 | 用动作替代 |
| "心里" | 3次 | 用身体反应替代 |
| "这就是" | 0次 | 删掉 |

#### 🟡 AI最爱的句式（禁用或严格限制）

| 句式 | 问题 | 替代 |
|------|------|------|
| "不只是X，而是Y" | 每个AI都用 | 直接说Y |
| "关键不在X，而在Y" | 清单万能句 | 改为具体论述 |
| "没有X。没有Y。只有Z。" | 三否定开场 | 用一个具体画面 |
| "无论你是X还是Y" | 覆盖所有人 | 删掉，直接切入 |
| "在X的世界里" | 模糊语境 | 用具体场景 |
| "想象一个X的世界" | 设问铺垫 | 直接写 |
| "X不仅仅是Y" | 空泛展开 | 写具体功能/效果 |

### 3.3 去AI味核心技法

#### 技法一：用动作替代感受

```
❌ 他感到一阵强烈的震惊
✅ 他嘴巴张了半天没合上

❌ 一股强大的气势压来
✅ 他感觉自己像被一座山砸了一下

❌ 他心中暗道
✅ 他心里骂了一句

❌ 他不知道说什么
✅ 林北看着他，没接话。
```

#### 技法二：用对话替代叙述

```
❌ 他很惊讶
✅ "卧槽？"苏小鱼说。

❌ 他很愤怒
✅ "你再说一遍？"老周的声音低了下来。
```

#### 技法三：用具体替代抽象

```
❌ 力量提升
✅ 他一拳打出去，练功石碎了

❌ 灵力运转速度提升
✅ 灵力在经脉里跑了一圈，比之前快了两成
```

#### 技法四：用碎片替代完整

```
❌ 他心中思绪万千，感到前所未有的复杂情绪
✅ 疼。真他妈疼。值吗？值。
```

#### 技法五：用环境替代抒情

```
❌ 他心情复杂，不知道该如何是好
✅ 窗外的雨一直没停
```

#### 技法六：用沉默替代表达

```
❌ 他不知道说什么好
✅ 林北看着他，没接话。
```

### 3.4 注入"人味"的三招

1. **插入主观句**："我真没想到她能笑得那么轻松"——这种人类判断AI学不来
2. **制造不完美**：有些逻辑刻意不解释，反而更真实
3. **多用语气词**："诶""哎呀""算了吧"——能立刻降低AI感

### 3.5 去AI味提示词模板

**场景1：口语化重写**
```
帮我审核这段内容，用对话感强、友好又不随意的真人语气重写。
全程用短句、简单词汇，删掉学术化表达、生硬过渡短语和企业官话。
让内容读起来就像一个人在用自己的大白话和朋友聊天。
保留核心观点，删掉所有多余的修饰。
```

**场景2：人类痕迹万能公式**
```
请按以下步骤重写文本：
①保留原文要点约60%
②加入至少1个口语化连接词
③加入至少1个个人视角限定语
④适当加入轻微冗余或倒装
```

## 四、网文写作技巧——节奏与爽点

### 4.1 节奏的本质

网文节奏 ≠ 写得快还是慢

**节奏 = 信息投放和情绪刺激的频率**

数据：追读率top10%作品，平均每1.8章一次情绪高峰；bottom10%平均4.7章。

### 4.2 爽点三级体系

| 级别 | 频率 | 效果 | 来源 |
|------|------|------|------|
| **小爽点** | 每章至少1个 | 嘴角微微上扬 | 主角说了句漂亮话、路人惊讶、小反转、小奖励 |
| **中爽点** | 每3-5章1个 | "啊这也太爽了" | 完整打脸流程、关系突破、实力跃升、谜题揭晓 |
| **大爽点** | 每卷高潮1个 | 想发截图到朋友圈 | Boss战逆转、身份曝光、多条伏笔同时回收 |

**关键：爽点类型要轮换，连续5章打脸会审美疲劳。**

### 4.3 章末钩子设计（追读命门）

> 读者决定要不要看下一章，就看你这章最后三行。

| 钩子类型 | 示例 | 适用场景 |
|---------|------|----------|
| **悬念式** | "门外传来一个声音，那是一个不可能出现在这里的人。" | 悬疑、危机 |
| **反转式** | 整章暗示A是凶手，最后一行发现B手上有血 | 推理、揭秘 |
| **情绪炸弹式** | "你从来就没把我当过朋友。"直接切掉 | 感情、冲突 |
| **信息投放式** | "他翻开日记最后一页，上面画着一张和自己一模一样的脸。" | 世界观展开 |
| **动作钩子** | 小一歪着脑袋看着他，笑脸歪歪扭扭的。 | 日常、温馨 |
| **环境钩子** | 窗外的雨越下越大了。 | 铺垫、过渡 |

### 4.4 经典节奏模板

#### 模板一：起承转爽（最通用）

```
起（章首500字）：简要回顾上章 + 引出本章冲突
承（中间800字）：冲突升级、压力增大
转（300字）：出现转折，绝望到希望/敌人露底牌
爽（400字）：主角反击/真相揭晓/意外收获 + 钩子结尾
```

#### 模板二：过山车（适合战斗章）

```
紧张 → 缓一口气 → 更紧张 → 以为结束了 → 最紧张 → 结束+钩子
```

关键在"以为结束了"那个假结局。

#### 模板三：信息揭露递进（适合悬疑/解谜）

```
线索A → 推理出结论1 → 发现不对劲 → 线索B推翻结论1 → 新推理 → 更大秘密浮现
```

### 4.5 章节结构公式

```
字数：2,300-2,500字（番茄标准）
结构：
  开头：承接上章，或新场景切入
  中段：推进剧情或展开搞笑
  结尾：钩子（让读者想看下一章）

节奏配比（搞笑类）：
  搞笑 : 打斗 : 剧情 = 7 : 1 : 2
```

### 4.6 网文黄金法则

1. **3万字内解决首个高潮**——压抑越久，爆发越爽
2. **主角打酱油≤3000字**——长时间离线=读者弃书
3. **铺垫最长不超过2章**——期间必须穿插小爽点
4. **每章必须有钩子**——没有钩子=帮读者按"退出"按钮
5. **日更4000字以上**——番茄全勤线

## 六、写作自检清单

### 每章完成后必须逐项检查：

```
□ 字数是否在 2,300-2,500 字之间？
□ 标题是否吸引人且与内容对应？
□ 有没有连续三个排比句？→ 有就改
□ 结尾是不是"这就是他的XXX"？→ 是就换
□ "眼神里有"出现几次？→ 超过0次就改
□ "心里有"出现几次？→ 超过3次就改
□ 感叹号超过5个？→ 减少到3个以内
□ "他自言自语"超过1次？→ 删掉多余的
□ "他摇了摇头"超过2次？→ 换成其他动作
□ "他深吸一口气"超过1次？→ 删掉
□ 角色对话有没有来有回？→ 不能全是独角戏
□ 章末钩子是不是和上章类型重复？→ 轮换类型
□ 数据是否正确且是整数？（灵石、经验、人数）
□ 角色说话是否符合各自的语言特征？
□ 商品出场是否用了三步法？
□ 系统提示是否有性格（不是冰冷的UI）？
□ 读出声来像不像人说的话？→ 不像就改
□ 是否有AI味的空洞描写？→ 替换成具体动作
□ 读者看完会不会想笑？→ 至少2个笑点
□ 读者看完会不会想一想？→ 至少1处深意
□ 读者看完会不会想看下一章？→ 钩子必须强
```

## 七、AI味30秒快速自检

审稿时用这个清单：

- [ ] 是否以"在当今……"或类似开场？
- [ ] 前200字里有没有3+个高频AI词？
- [ ] 每个句子长度都一样吗？（AI均匀分布）
- [ ] 段落都用"此外"、"而且"开头吗？
- [ ] 有没有具体的数字、人名、日期？
- [ ] "深入探讨"、"利用"、"强大"用超过一次了吗？
- [ ] 有个人语气、观点、轶事吗？
- [ ] 大声读给朋友听会不会尴尬？

**前6题有4+个"是"，且7和8题是"否" → 必须重写。**

## 一、2026 AI小说工具全景

### 1.1 工具分层格局

2026年AI写小说市场已形成清晰的产品分层：

| 层级 | 定位 | 代表工具 | 核心能力 |
|------|------|---------|---------|
| **专业创作工作台** | 全流程长篇创作 | FeelFish 4.0、StoryForge、AI-Novel-Writing-Assistant | 百万字全文记忆、多智能体协作、世界观管理 |
| **通用大模型基座** | 推理+生成 | DeepSeek、GPT-4o、Gemini、Qwen、Kimi | 超长上下文、逻辑推理、风格模仿 |
| **网文垂直工具** | 批量生产 | 蛙蛙写作、新月写作 | 多端同步、5000+预制工作流、网文生成器 |
| **开源系统** | 可定制 | StoryForge、AI-Novel-Writing-Assistant、MultiAgentWriter | Agent编排、RAG、写法引擎 |

### 1.2 核心工具深度对比

#### FeelFish 4.0 — 专业小说创作工作台
- **交互模式**：对话即创作，自然语言驱动
- **核心突破**：百万字全文记忆 + 全文检索问答
- **多智能体**：支持"编辑部"创作、"质检部"审查、"素材部"收集等分工
- **模型兼容**：原生接入 DeepSeek、ChatGPT、Gemini、Grok、豆包、Qwen、Kimi 等10+模型
- **特色功能**：移动端远程控制、项目时光机(30天版本回溯)、AI封面生成
- **资费**：每月500万免费积分，会员≥17元/月

#### StoryForge — 开源小说创作工作台
- **架构**：Tauri桌面 + React前端 + FastAPI后端
- **核心理念**：提示词完全可见、可编辑、可保存
- **功能**：
  - 故事设计7字段（logline、high concept、主题、核心冲突、故事模式、主线/复线）
  - 角色6级分级（主角→路人）
  - 力导图可视化角色关系网
  - 创作规则（写作风格、叙事视角、基调氛围、禁忌列表）
  - 3条内置工作流：极速起书、专业创作、深度定制
- **GitHub**：github.com/yuanbw2025/storyforge

#### AI-Novel-Writing-Assistant — AI导演式生产系统
- **定位**：面向完全不懂写作的新手，从一句灵感走到完整小说
- **核心链路**：灵感 → AI自动导演 → 世界观 → 角色 → 卷战略 → 章节执行 → 审核修复
- **技术栈**：LangGraph Agent编排、Qdrant RAG、SQLite/Prisma
- **写法引擎**：可保存、编辑、绑定、试写、复用的长期资产
- **反AI规则**：减少模板感、解释感和空泛表达
- **衍生工坊**：漫画工作台、短剧改编生产管线
- **GitHub**：github.com/ExplosiveCoderflome/AI-Novel-Writing-Assistant

#### MultiAgentWriter — 多智能体协作系统
- **Agent架构**：Planner → Writer → Critic → Revise
- **技术**：Celery任务队列、ChromaDB向量检索、NovelState叙事状态管理
- **特色**：Guardrails字数与结构守护、SkillAssembler作家风格注入

### 1.3 通用大模型选择策略

| 任务类型 | 推荐模型 | 原因 |
|---------|---------|------|
| 构思/大纲 | DeepSeek / GPT-4o | 逻辑推理精度高 |
| 正文续写 | Qwen / Kimi | 中文语感好，文学性强 |
| 润色/改稿 | Claude / Gemini | 细腻度和风格控制出色 |
| 世界观设定 | DeepSeek | 超长上下文，复杂设定不遗漏 |
| 对话写作 | GPT-4o / Qwen | 对话自然流畅 |
| 风格模仿 | Claude | 风格一致性最强 |

## 二、小说创作核心方法论

### 2.1 故事结构体系

#### 三幕式结构（经典）
```
第一幕（25%）：建置
  - 日常世界展示
  - 激励事件（打破平衡）
  - 第一转折点（决定踏上旅程）

第二幕（50%）：对抗
  - 试炼与盟友
  - 中点反转（真假胜利）
  - 一无所有时刻（最大危机）
  - 第二转折点（获得最终钥匙）

第三幕（25%）：解决
  - 高潮对决
  - 新平衡建立
```

#### 英雄之旅（坎贝尔12阶段）
1. 平凡世界 → 2. 冒险召唤 → 3. 拒绝召唤 → 4. 导师相遇
5. 跨越第一道门槛 → 6. 试炼、盟友与敌人 → 7. 接近最深的洞穴
8. 磨难 → 9. 报酬 → 10. 返回之路 → 11. 复活 → 12. 携万灵丹归来

#### 网文多幕结构
```
卷级结构：每卷=一个完整三幕
  卷1：入门+初显锋芒
  卷2：成长+势力扩展
  卷3：危机+逆转突破
  卷4：高潮+终极对决
  ...
节奏控制：每3-5章一个小高潮，每15-20章一个大高潮
```

#### 故事模式选择
| 模式 | 特点 | 适用 |
|------|------|------|
| 线性叙事 | 单线推进，因果清晰 | 爽文、升级流 |
| 莲花地图 | 多线并行，最终汇聚 | 群像、悬疑 |
| 多线并行 | 多主角交替叙事 | 史诗、权谋 |
| 蒙太奇 | 时空跳跃，碎片拼接 | 文艺、意识流 |
| 环形叙事 | 首尾呼应，闭合结构 | 寓意型作品 |

### 2.2 人物设计体系

#### 角色层级分类
| 层级 | 字段 | 说明 |
|------|------|------|
| **主角** | 全字段大卡片 | 弧光完整、心理戏多、成长线贯穿 |
| **重要配角** | 大卡片 | 有独立弧光，与主线深度绑定 |
| **次要角色** | 小卡片3列 | 有戏份但不主导 |
| **NPC** | 紧凑列表 | 常驻但不出场的关键人物 |
| **路人** | 5列表格 | 一笔带过的群像 |

#### 人物卡片必填项
```
基础信息：姓名、年龄、外貌、身份
性格维度：核心特质（3个关键词）、性格缺陷、隐藏面
动机系统：表面目标、深层需求、内心恐惧
成长弧光：起点状态 → 触发事件 → 挣扎 → 转变 → 终点状态
关系网络：与每个关键角色的关系（亲属/师友/敌对/暧昧/合作/竞争）
标志性特征：口头禅、习惯动作、独特记忆点
```

#### 人物弧光类型
- **正向弧光**：缺陷→觉醒→成长（王道热血）
- **负向弧光**：光明→堕落→毁灭（悲剧）
- **平坦弧光**：信念坚定→改变世界（信念型主角）
- **扭曲弧光**：看似成长实则原地打转（反讽型）

### 2.3 节奏控制技术

#### 四镜头法（借鉴电影叙事）
- **全景镜头**：世界观铺垫、大场景描写
- **中景镜头**：人物互动、情节推进
- **近景镜头**：情感细节、内心独白
- **特写镜头**：关键道具、决定性瞬间

#### 节奏公式
```
张力曲线 = 信息差 × 情感强度 × 时间压力

每章节奏公式：
  开头钩子（前3段抓人）
  + 冲突推进（中段制造张力）
  + 部分解密（满足当前期待）
  + 新悬念（结尾抛出新钩子）
```

#### 爽点设计
- **打脸爽**：先压后扬，反差越大越爽
- **升级爽**：能力突破+新地图开启
- **揭秘爽**：伏笔回收+真相大白
- **逆袭爽**：绝境翻盘+以弱胜强
- **社交爽**：他人认可+身份揭示

### 2.4 世界观构建

#### 世界观清单
```
□ 世界基础设定（物理法则、魔法/科技体系）
□ 地理与势力分布
□ 历史与文明脉络
□ 社会制度与权力结构
□ 经济体系与资源分配
□ 文化与信仰体系
□ 特殊规则与禁忌
□ 力量等级体系（如有）
□ 种族与物种（如有）
□ 地图与势力图谱
```

## 三、学术前沿：AI长篇生成研究

### 3.1 六大研究方向（2025-2026）

| 方向 | 代表论文 | 会议 | 核心贡献 |
|------|---------|------|---------|
| **长篇生成** | Learning to Reason for Long-Form Story Generation | COLM 2025 | 用RL训练推理能力 |
| **层级规划** | DOME (Dynamic Hierarchical Outlining + Memory-Enhancement) | NAACL 2025 | 动态大纲+记忆增强 |
| **一致性检测** | ConStory-Bench (Lost in Stories) | ACL 2026 | LONGSTORY数据集+矛盾检测 |
| **多智能体** | StoryBox (Collaborative Multi-Agent Simulation) | AAAI 2026 | 混合自底向上+自顶向下 |
| **角色驱动** | From Personas to Plot | 2026 | 角色grounded多Agent长篇生成 |
| **风格控制** | 风格蒸馏研究 | 多个 | 语言层风格模仿已基本解决 |

### 3.2 学术界的六大判断

1. **判断1**：短中篇(<3万字)生成质量已接近人类水平
2. **判断2**：超长篇(>10万字)全局一致性，还是没解决 ⚠️
3. **判断3**：风格模仿(语言层)已经做得很好 ✅
4. **判断4**：创意和新意，是AI最短的板 ⚠️
5. **判断5**：高级叙事技巧（伏笔、隐喻、象征），研究极少
6. **判断6**：中文小说生成研究明显少于英文

### 3.3 关键技术突破

#### 上下文管理
- **全文记忆**：百万字级别的全文检索问答（FeelFish）
- **RAG召回**：世界观、角色、拆书知识库按需注入（Qdrant/ChromaDB）
- **状态回灌**：每章完成后角色状态、事实、伏笔回写系统

#### 多智能体协作
```
Planner（策划）→ 世界观+大纲+卷战略
  ↓
Writer（编剧）→ 场景展开+对话+细节扩写
  ↓
Critic（审查）→ 逻辑硬伤+一致性+质量评分
  ↓
Revise（修复）→ 定向修订+质量债务记录
  ↓
回灌 → 更新角色状态、伏笔追踪、下一章上下文
```

#### 写法引擎（写作规则系统化）
- 从参考文本提取写法特征 + 原文样本
- 特征池可视化：逐项启用/停用/组合
- 参与生成、检测和修正链路
- 反AI规则：减少模板感、解释感、空泛表达

## 四、AI辅助创作实战流程

### 4.1 全流程工作流

```
Phase 1: 灵感捕捉
  └─ 一句话核心梗概（≤25字：题材+主角+核心冲突）

Phase 2: 项目设定
  └─ 题材、卖点、目标读者感受、前30章承诺

Phase 3: 世界观构建
  └─ 世界起源 → 地理 → 势力 → 历史 → 规则

Phase 4: 角色设计
  └─ 主角 → 核心配角 → 反派 → 关系网

Phase 5: 故事宏观规划
  └─ 故事模式选择 → 主线/复线设计 → 爽点分布

Phase 6: 卷级规划
  └─ 分卷策略 → 每卷三幕 → 卷间衔接

Phase 7: 章节拆分
  └─ 当前卷 → 章节列表 → 单章细纲

Phase 8: 正文写作
  └─ 单章生成 → AI审核 → 修复 → 状态回灌

Phase 9: 质量把控
  └─ 逻辑校验 → 一致性检测 → 润色 → 定稿
```

### 4.2 分步执行要点

#### Step 1: 核心梗概
```
格式：[题材] + [主角] + [核心冲突] + [独特卖点]
示例：
❌ "写一个修仙小说"
✅ "废材少年偶得上古传承，在宗门倾轧中逆袭成仙，主打打脸爽+势力扩张"
```

#### Step 2: 人物卡设计（最重要！）
```
⚠️ 必须在写正文前完成完整人物卡
⚠️ 弱点、执念必须写清楚，否则后期人设跑偏
⚠️ 每个角色需要：起点→终点 的明确弧光
```

#### Step 3: 大纲确认制
```
每一阶段必须人工确认后再进入下一步：
  核心梗概 → 确认 → 世界观 → 确认 → 角色 → 确认 → 大纲 → 确认 → 正文

⚠️ 不要跳步！不要让AI一口气写完整本！
```

#### Step 4: 正文生成控制
```
每次只生成1章（约3000-5000字）
生成后立即检查：
  □ 人物言行是否符合设定
  □ 剧情是否偏离大纲
  □ 节奏是否张弛有度
  □ 是否有新钩子/伏笔
确认后再进入下一章
```

### 4.3 长篇一致性维护

#### 角色一致性
- 每章生成前注入：当前出场角色的完整卡片
- 每章生成后更新：角色状态变化、新获得的信息
- 使用角色关系图谱防止关系错乱

#### 剧情一致性
- 伏笔追踪表：记录每个埋下的伏笔和回收计划
- 时间线维护：确保事件顺序不混乱
- 因果链检查：每个事件必须有合理前因

#### 世界观一致性
- 规则冲突检测：新设定不能与已有规则矛盾
- 力量体系校验：战力不能随意膨胀
- 地理一致性：移动距离和时间要合理

## 五、提示词工程：小说专用Prompt体系

### 5.1 五大核心提示词模块

#### 模块1：世界观与背景设定
```
你是一位资深世界观架构师。请为以下小说构建完整的世界观：

【基本框架】
- 题材类型：{genre}
- 时代背景：{era}
- 核心设定：{core_setting}

【要求】
1. 构建自洽的物理/魔法/科技法则体系
2. 设计地理环境与势力分布
3. 梳理历史脉络与文明发展
4. 明确社会制度与权力结构
5. 设计经济体系与资源分配
6. 标注与故事核心冲突直接相关的特殊规则

【输出格式】
按层级结构输出，每个模块附带"对剧情的影响"说明
```

#### 模块2：人物设定
```
你是一位专业角色设计师。请为以下角色创建完整人物卡：

【角色定位】
- 角色层级：{protagonist/major/minor/npc}
- 在故事中的功能：{function}
- 与其他角色的关系：{relationships}

【人物卡模板】
1. 基础信息：姓名、年龄、外貌（3个标志性特征）
2. 性格矩阵：核心特质(3词) | 性格缺陷 | 隐藏面 | 口头禅
3. 动机系统：表面目标 → 深层需求 → 内心恐惧
4. 成长弧光：起点 → 触发 → 挣扎 → 转变 → 终点
5. 能力体系：核心能力 | 致命弱点 | 成长空间
6. 标志性记忆：最幸福的回忆 | 最痛苦的回忆 | 改变人生的事件

【特别要求】
- 每个弱点必须有来源（不是凭空出现的缺陷）
- 成长弧光必须有具体触发事件
- 标注该角色如何推动主线剧情
```

#### 模块3：全书大纲
```
你是一位叙事结构大师。请为以下小说设计完整大纲：

【基本信息】
- 核心梗概：{logline}
- 计划字数：{word_count}
- 故事模式：{linear/multi-line/loop}
- 目标读者感受：{reader_feeling}

【大纲结构要求】
1. 全书分为{N}卷，每卷包含完整三幕结构
2. 每卷标注：核心冲突、高潮点、卷间衔接
3. 主线清晰，2-3条支线交织
4. 爽点分布：每3-5章一个小爽点，每15-20章一个大爽点
5. 伏笔表：列出所有需要埋设和回收的伏笔
6. 节奏曲线：标注每卷的情感强度变化

【输出格式】
卷级大纲 + 章节列表（每章一句话概括）
```

#### 模块4：单章细纲
```
你是一位章节设计师。请为第{N}章设计详细细纲：

【上下文】
- 上一章结尾：{last_chapter_end}
- 本章需要推进的剧情点：{plot_points}
- 本章出场角色：{characters}
- 本章需要埋设/回收的伏笔：{foreshadowing}

【细纲要求】
1. 开头钩子：前3段必须制造悬念或冲突
2. 场景分解：每个场景标注[地点][人物][事件][情感基调]
3. 冲突设计：至少1个核心冲突 + 1个小摩擦
4. 对话要点：关键对话的情感走向和信息传递
5. 结尾设计：必须抛出新悬念或制造情感落差
6. 节奏标注：紧张/舒缓/高潮 的节奏分布

【字数控制】
目标{target_words}字，场景数量{scene_count}个
```

#### 模块5：正文写作
```
你是一位{genre}小说作家，风格参考{style_reference}。

【本章任务】
{chapter_outline}

【写作规则】
1. 叙事视角：{first_person/third_person_limited/third_person_omniscient}
2. 时态：{past/present}
3. 基调：{tone}
4. 节奏：{pacing_notes}

【角色约束】
{character_cards_for_this_chapter}

【禁忌清单】
- 禁止使用"突然"、"忽然"开头的转折
- 禁止大段心理独白替代行动
- 禁止无意义的环境描写（每段描写必须服务剧情或氛围）
- 禁止角色做出不符合其性格设定的行为
- 禁止使用"仿佛"、"好像"超过3次/千字
- 禁止信息倾倒（世界观设定必须通过剧情自然展现）

【质量标准】
- 每段对话必须有潜台词
- 每个场景必须推动剧情或角色成长
- 感官描写至少覆盖3种感官
- 结尾必须有钩子
```

### 5.2 提示词优化技巧

#### 角色设定优化
```
❌ "请设计一个强大的主角"
✅ "请设计一个表面冷漠实则重情的剑修，他有社交恐惧症（源于幼年被背叛），
    目标是找到失散的妹妹，内心恐惧是再次被抛弃。
    他的成长弧光是从独行侠到学会信任同伴。"
```

#### 剧情生成优化
```
❌ "请写一章精彩的战斗"
✅ "这是主角第一次使用新觉醒的能力。场景在暴雨中的悬崖边。
    对手是曾经的师兄（现在知道是灭门仇人）。
    主角需要在战斗中做出选择：杀死仇人还是救下即将坠崖的无辜村民。
    这个选择将决定他后续的成长方向。请写出战斗过程中的心理挣扎。"
```

#### 风格控制优化
```
❌ "请写得文学一点"
✅ "参考余华的叙事风格：简洁克制的语言，通过细节而非议论传递情感。
    短句为主，避免形容词堆砌。用动作和对话展现人物心理，不直接描写内心。
    保持冷静的叙事距离，让读者自己感受冲击。"
```

## 六、避坑指南与最佳实践

### 6.1 十大避坑原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **分步确认** | 每一步审核满意后再继续，不要跳步 |
| 2 | **人物先行** | 正文前必须完成完整人物卡（含弱点和执念） |
| 3 | **不要一口气生成** | 单次输出token有限，一次写完整本只会得到残缺开头 |
| 4 | **上下文管理** | 长篇必须有世界观/角色/大纲的记忆机制 |
| 5 | **伏笔追踪** | 建立伏笔表，记录埋设位置和回收计划 |
| 6 | **节奏检查** | 每5章回顾一次节奏曲线，避免平铺直叙 |
| 7 | **一致性校验** | 定期检查人物言行、世界观规则是否自洽 |
| 8 | **现实题材联网** | 涉及真实行业/历史时，开启联网搜索保证准确 |
| 9 | **版本管理** | 每次重大修改前备份，支持回退 |
| 10 | **人机协同** | AI是助手不是枪手，最终质量取决于作者审美判断 |

### 6.2 常见崩盘模式

```
❌ 人设崩坏：后期角色做出前期不可能做的事
   → 解决：完整人物卡 + 每章注入角色约束

❌ 剧情跑偏：写着写着偏离最初设定
   → 解决：大纲锚定 + 每章对照大纲检查

❌ 节奏失控：连续10章都在铺垫没有高潮
   → 解决：节奏曲线图 + 强制爽点分布

❌ 力量膨胀：主角后期无敌导致无冲突
   → 解决：力量等级预设 + 每次升级伴随新限制

❌ 伏笔遗忘：前面埋的线后面忘了收
   → 解决：伏笔追踪表 + 定期清理

❌ 设定矛盾：世界观规则前后不一
   → 解决：设定文档化 + 新设定冲突检测
```

### 6.3 最佳实践总结

#### 工具选择
- **新手入门**：FeelFish（门槛低，免费额度充足）
- **专业创作**：AI-Novel-Writing-Assistant（完整生产链）+ StoryForge（精细控制）
- **网文量产**：蛙蛙写作（工作流丰富）+ 新月写作（生成器齐全）
- **极客定制**：开源系统 + 自选大模型API

#### 工作流建议
1. **先规划后执行**：花30%时间在规划上，节省70%的返工
2. **小步快跑**：每次只写1-2章，快速迭代
3. **多模型切换**：构思用推理强的模型，写作用语感好的模型
4. **建立资产库**：世界观、人物卡、写法规则都保存为可复用资产
5. **定期回顾**：每完成一卷，回头通读检查一致性

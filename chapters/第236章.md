# 第236章 系统又给惊喜了

林北盯着系统面板，眼睛一眨不眨。

苏小鱼凑过来，嘴里还嚼着红薯。"怎么了？你脸色变了。"

"系统解锁新商品了。"林北说。

"新商品？"苏小鱼来了兴趣，"什么商品？给我看看。"

【新商品：幻境香】

【功效：点燃后，方圆十丈内所有人陷入幻境，持续半个时辰。】

【对金丹期有效率：100%。对元婴期有效率：80%。对化神期有效率：30%。】

【定价：65块灵石。】

【副作用：点燃者也会受到轻微影响，会看到自己内心最深处的执念，持续约十个呼吸。】

【提示：幻境中的人会说出真心话，请谨慎使用。】

这玩意，厉害了。

方圆十丈内所有人陷入幻境，金丹期百分百中招，元婴期也有八成把握。

但他也注意到了两个问题。

"林北？"苏小鱼叫他，"你发什么呆？新商品到底是什么？"

"幻境香。"林北说，"点燃后能让方圆十丈内所有人陷入幻境，金丹期百分百中招，元婴期八成。"

苏小鱼愣了一下。"所有人？包括自己？"

"点燃者只受影响十个呼吸，中招的人沉浸半个时辰。"

"那还挺厉害的。"苏小鱼说，"不过你那些坑人的商品，哪个没副作用？上次那个通络排毒散，我师兄吃了之后在宗门大殿上放了整整三个时辰的屁，差点被长老逐出师门。"

"副作用是幻境中的人会说真心话。"林北说，"包括我自己。"

苏小鱼的表情变得微妙。"说真心话？那如果你在幻境里把系统的事说出去……"

"所以我得想办法。"林北皱眉，"可以在点燃之前吃一颗清心丸，宁神静气，抵抗幻术。虽然不一定能完全抵消，但至少能缩短受影响的时间。"

"从十个呼吸缩短到多少？"

"不知道，得试了才知道。"林北说，"但这是目前最好的办法。而且幻境香的妙处在于，它不是直接攻击，而是让敌人自己暴露弱点。你想啊，一个人在幻境里看到自己最深的执念，他会怎么做？他会不顾一切地去追求。那时候，他的防御就是零。"

苏小鱼想了想，觉得有道理。"那你打算什么时候用？"

"留着。"林北说，"这东西太金贵了，不能随便浪费。得等到真正危急的时候再用。"

他从货架上拿下一盒幻境香，打开来看。盒子里装着三根紫色的香，每根只有手指长短，表面泛着淡淡的光泽，闻起来有一股淡淡的甜味。

"就这三根？"苏小鱼问。

"系统每天只生成一盒，一盒三根。"林北说，"卖完就没了。二十五块灵石一根，七十五块一盒。"

"挺贵的。"

"贵是贵了点，但效果好。"林北把盒子收好，"这东西不能随便卖，得留着关键时刻用。"

他正说着，小三从门外飘进来。

"主人~"小三说，"我刚才在外面听到一个消息。"

"什么消息？"

"巷口的张大婶说，坊市外面来了几个陌生人，穿着灰衣服，脸上蒙着布，看着不像好人。他们在坊市外面转悠了大半天，也不进来，就在外面盯着。"

林北的表情变了。

"几个？"

"三个。"小三说，"张大婶说他们从中午就在那了，一直没走。"

林北和苏小鱼对视一眼。

"天机阁的人？"苏小鱼问。

"八成是。"林北说，"假死丹的药效只有三天，他们肯定已经发现我没死了。"

"那你怎么办？"

林北想了想，从柜台下面拿出一包迷幻粉和一包驱兽粉，又从货架上拿了三颗清心丸。

"先准备着。"他说，"如果他们敢进来，我就让他们尝尝这些好东西。"

"这些东西对元婴期有用吗？"苏小鱼怀疑地说。

"迷幻粉对金丹期有用，对元婴期效果减弱。"林北说，"但配合幻境香，应该能撑一阵。而且别忘了，进了我的店，再强的人也得变炼气期。"

苏小鱼点点头。店铺压制的规则她清楚，这是林北最大的依仗。

"小三。"

"在~"

"你去门口盯着，如果那三个灰衣人靠近坊市大门，马上告诉我。"

"好的主人~"小三飘了出去。

苏小鱼站起来，拔出腰间的短剑。"我也去帮忙。"

"你别出去。"林北说，"你刚回来，还没休息好。而且你是金丹巅峰，出去了反而会暴露我们的底牌。让他们以为坊市里只有我一个金丹初期，轻敌了才好对付。"

"那你一个人应付？"

"我不是一个人。"林北说，"我有系统，有店铺，还有小一到小四。实在不行，还有老周。"

苏小鱼看着他，犹豫了一下，最终点了点头。"行，那你小心。"

林北笑了笑。"放心，兄弟我命硬。"

他坐回柜台，把清心丸放在手边，又把幻境香的盒子打开放在抽屉里，随时准备点燃。

然后他心里过账，假装在记账。

过了大约半个时辰，小三飘回来，压低声音说："主人，那三个灰衣人往北门方向走了。"

"走了？"

"嗯，但我觉得他们还会回来。他们走之前在坊市门口站了好一会儿，盯着杂货铺的方向看了很久。"

林北点点头。天机阁的暗探，不会这么轻易放弃。假死丹骗了他们一次，他们不会再上第二次当。

"小三，你今晚别睡了，帮我盯着。"

"好的主人~"小三说，"主人放心，我晚上视力特别好~"

"你又不是猫。"

"我是人偶嘛，人偶不睡觉的~"

林北摆了摆手，让小三去门口守着。

然后他看着系统面板上的幻境香说明，脑子里开始盘算。

幻境香，配合清心丸，再配合迷幻粉和驱兽粉。

这是一套组合拳。

如果天机阁的人真的敢闯进来，他就用这套组合拳招待他们。

天机阁是大宗门，不会因为一次失败就放弃。他们还会派更强的人来。

他需要更强的底牌。

"系统，"他在心里问，"有没有什么能对付元婴期以上修士的商品？"

【当前系统等级：Lv.11。已解锁商品：全部展示完毕。】

【下一批商品解锁条件：系统升级到Lv.12，需要经验值80,000。】

【当前经验：10,280 / 80,000。】

林北叹了口气。

差了整整六万四千多。两百多天，半年多。

天机阁的人可不会等他半年。

得想办法加速积累。

除非找到大宗门或者大势力，一次性卖出大量商品。

现在时间不够。

"走一步看一步吧。"林北自言自语。

他把幻境香收好，吹灭了柜台上的蜡烛。

窗外，月亮升起来了。

小三在门口站岗，红宝石眼睛在黑暗中闪闪发光。

脑子里全是幻境香的说明——"幻境内容为中招者内心最深处的执念"。

最深处的执念。

他自己的执念是什么？

是回到前世？还是在这个世界活下去？是查清父亲的死因？还是保护好这个杂货铺？

他不知道。

所以，清心丸必须吃。而且得提前吃。

他翻了个身，闭上眼。

明天，天机阁的人可能会来。

他得做好准备。

他不知道的是，就在他入睡的时候，坊市北门外三里处的一棵大树上，三道灰影正盯着杂货铺的方向。

为首的灰影低声说："确认了，林北没死。假死丹的药效过了，他又活了。"

"周大人那边怎么说？"

"回去禀报，让他定夺。"

三道灰影消失在夜色中。

风还在吹。

夜还很长。

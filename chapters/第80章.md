# 第80章 Lv.5，传说级商品来了

升级之后的第一件事，林北是把新商品摆上货架。

转世丹，一百灵石一颗。灰扑扑的药丸，闻起来有股泥土味。

命运硬币，五十灵石一枚。铜色的硬币，两面都刻着"运"字。

因果线，八十灵石一根。银色的细线，摸起来温温的，像有生命一样。

林北把三样东西摆在货架上，退后几步看了看。

转世丹。命运硬币。因果线。

传说级的商品。

"系统，这三个商品有没有什么副作用？"

【转世丹：服用后会经历一次"死亡"，然后重生。天赋提升一个等级。】

【命运硬币：抛出后，正面修为翻倍。副作用：两面都是正面。】

【因果线：绑定后，一人受伤另一人替承受一半。副作用：两人会逐渐心意相通。】

林北点点头。

副作用还是有的。

转世丹要"死"一次。

命运硬币两面都是正面。

因果线会让两个人心意相通。

但这些副作用，比之前的"浑身疼三天"和"放屁三个时辰"温和多了。

至少不会社会性死亡。

"小一。"

"在---"

"帮我更新价目表。"

"是---"

林北拿出纸笔，重新写了一张价目表：

```
林氏杂货铺·新品上市

转世丹：100灵石/颗
功效：重生后天赋提升一个等级
副作用：会经历一次"死亡"

命运硬币：50灵石/枚
功效：抛正面修为翻倍
副作用：两面都是正面

因果线：80灵石/根
功效：绑定后一人受伤另一人替承受一半
副作用：两人会逐渐心意相通

注：所有商品均附带防伪印记，请认准正品。
```

他把价目表贴在门口。

然后，他坐在柜台后面，等着第一个客人。

等了半个时辰，来了。

是个年轻修士，穿着青色道袍，腰间挂着一块玉牌。

青云宗的弟子。

"老板，"他走进店里，"我听说你这有新货？"

"对。"林北说，"转世丹、命运硬币、因果线。"

"命运硬币？"年轻修士的眼睛亮了，"抛正面修为翻倍？"

"对。"林北说，"五十灵石一枚。"

"副作用呢？"

"两面都是正面。"

年轻修士愣住了。

"两面都是正面？那不是......怎么抛都是正面？"

"对。"林北说，"所以你永远是'运气好'。"

年轻修士想了想，觉得有道理。

"那不是必赢？"

"对。"林北说，"但你得花五十灵石买一枚硬币。"

年轻修士掏出灵石，数了五十块放在柜台上。

"来一枚。"

林北递了一枚命运硬币过去。

年轻修士接过硬币，看了看。

铜色的硬币，两面都刻着"运"字。

"抛吧。"林北说。

年轻修士把硬币往天上一抛。

硬币在空中转了几圈，落下来。

正面。

"我抛到正面了！"年轻修士惊喜。

"当然。"林北说，"两面都是正面。"

年轻修士愣了一下，然后笑了。

"也是。那我的修为......"

"翻倍了。"林北说。

年轻修士闭上眼睛，感受了一下。

"真的！我的灵力......翻倍了！"

"恭喜。"林北说。

年轻修士激动得浑身发抖。

"老板，你这硬币......太神了！"

"谢夸。"林北说，"但记住，下次再买，还是五十灵石。"

"没问题！"年轻修士说，"我要买十枚！"

"十枚？"林北挑了挑眉，"你要抛十次？"

"不是。"年轻修士说，"我要推荐给我的师兄弟们。他们也想修为翻倍。"

林北笑了。

"欢迎欢迎。团购打折。"

年轻修士点点头，拿着硬币走了。

林北看着他离去的背影，心里想：

命运硬币的第一个顾客，成功了。

口碑，又传出去了。

"系统，命运硬币的销售数据怎么样？"

【累计销售：1个。】

【顾客满意度：S级。】

【获得经验值：+50。】

S级满意度。

林北看着货架上的转世丹和因果线，笑了。

命运硬币的路子走通了。

接下来，该推转世丹和因果线了。

这两个商品，比命运硬币更贵，也更特殊。

转世丹要"死"一次，因果线要"绑定"一个人。

怎么卖呢？

得找合适的顾客。

一个愿意"死"一次的人。

一个愿意"绑定"另一个人的人。

慢慢来吧。

反正他的店又不会跑。

但林北没想到的是，转世丹的第一个顾客，来得比他想象的快。

下午，一个老者走进店里。

白发苍苍，气息微弱，走路都有些颤颤巍巍。

"老板，"老者开口了，声音沙哑，"我听说你这有转世丹？"

"有。"林北说，"一百灵石一颗。"

"吃了之后，天赋会提升？"

"对。"林北说，"但会经历一次'死亡'。"

"死亡？"

"呼吸心跳全无，和真死一样。"林北说，"但之后会重生，天赋提升一个等级。"

老者沉默了一下。

"我今年一百二十岁了。"他说，"筑基巅峰，卡了六十年。"

一百二十岁。

筑基巅峰。

卡了六十年。

林北看着他。

这个老者，已经没有多少时间了。

如果再不突破，就会老死。

"您想用转世丹突破？"林北问。

"对。"老者说，"我已经没有别的办法了。"

林北看着他，心里有些感慨。

一百二十岁。

筑基巅峰。

卡了六十年。

这就是修仙界的残酷。

天赋不够，再努力也没用。

但转世丹，可以改变天赋。

"好。"林北说，"一百灵石。"

老者从怀里掏出一个布袋，放在柜台上。

"这是一百灵石。"他说，"我攒了三十年。"

三十年。

林北接过布袋，数了数。

一百块灵石，一块不多，一块不少。

"好。"他说，"转世丹给您。"

他从货架上拿下一颗转世丹，递给老者。

老者接过药丸，看了看。

灰扑扑的药丸，闻起来有股泥土味。

"吃了之后，真的会'死'？"老者问。

"会。"林北说，"但之后会重生。"

"重生之后，天赋真的会提升？"

"会。"林北说。

老者点点头。

"好。我吃。"

他把药丸放进嘴里，咽了下去。

几秒钟后，他的身体开始僵硬。

呼吸停止了。

心跳停止了。

脉搏停止了。

体温开始下降。

他倒在了地上，一动不动。

林北蹲下身子，探了探他的鼻息。

没有。

摸了摸他的脉搏。

没有。

看了看他的瞳孔。

散了。

"......"

如果不是亲眼看着他吃药，林北真的会以为他死了。

"小一。"

"在---"

"把他搬到后屋，找个干净的地方放着。"

"是---"

小一把老者搬到了后屋。

林北坐在柜台后面，等着。

等老者重生。

等天赋提升。

等一个一百二十岁的老人，重新获得新生。

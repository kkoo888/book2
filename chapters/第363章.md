# 第363章 接

林安接了这家，是林北走的那年春天。

接得很顺。不是因为他早准备好了。是因为这一族人，都帮着他。

林北走的那天，全青木坊市，又关了门。跟老周走那回一样。街上静得，能听见风。

可这一次，没慌。因为这一族人，晓得该干什么。

"少爷，"周大说，"有什么要出力的，您说一声。"

"不用叫少爷。"林安说，"叫我林安。"

"那不行。"周大说，"叫了八年少爷，改不了口。"

"那就叫。"林安笑了，"随你。"

张铁匠来了："少爷，铺子里缺什么，我打。"

李婶的儿子来了："少爷，街上我看着。"

王德发的儿子来了："少爷，账我帮您算。"

林安看着这一街的人，忽然懂了他爹那句"一族人守"。

不是他一个人接手。是一族人，接着守。

头一件事，是记账。林安把那本账，翻到新的一页，写上：今日，林安接手。

备注：爹走了。这一本账，我接着记。

写完，他又添一句。

备注二：别丢人。宁亏灵石，不亏人。

这一句，他写得很正。一笔一画，跟他爹一个路数。

"小系。"

【在。】小系说，【我在。】

"你跟了我爹八年，"林安说，"往后，也跟着我？"

【跟着。】小系说，【你爹让我，看着这一族。】

"那你看好了。"

【看好了。】小系说。

"小系，"林安说，"你跟我爹，都说了些什么？"

【什么都说了。】小系说，【他这八年，一天一天，我都记着。】

"那你也记记我。"

【记着。】小系说，【从今天起。】

林安笑了。"那你，往后也多教教我。"

【教你什么？】

"教我，"林安想了想，"怎么守。"

【这个，】小系说，【你爹教过了。照着做就行。】

"那我爹，"林安说，"是怎么做的？"

【一天一天，守。】小系说，【不急。不慌。不贪。】

林安把这六个字，记在心里。

不急。不慌。不贪。

这六个字，就是他爹，教他的一辈子。

"还有，"林安说，"那本抄本，我搁在柜台上了。跟那本，一块儿。"

【看见了。】小系说，【两本账，一块儿，就是这间铺子的魂。】

"对。"林安说，"魂在，铺子就在。"

"小系，"他说，"你说，我比得上我爹吗？"

小系，停了很久。

【比不上。】它说。

林安笑了。"那当然。他是我爹。"

【可你，】小系说，【有你的样子。】

"什么样子？"

【守着。】小系说，【像他那样，守着。】

"那我，"林安说，"就守着。"

【守着。】小系说。

第二件事，是碑前。林安每天早上，去碑前，看日出。

他把林守，也带上。

"林守，"他说，"给你老守爷爷，问好。"

"老守爷爷好。"林守说。

碑上，敲一下。

"它敲了！"林守笑了。

"它应你了。"林安说，"往后，你天天来，它天天应。"

"天天来。"林守说。

"对。"林安说，"天天来。"

"天天来，"林守说，"做什么？"

"看日出。"林安说，"陪老守爷爷。"

"陪它做什么？"

"陪它，"林安想了想，"不孤。"

林守似懂非懂，点了点头。

"那我陪。"他说。

林安摸了摸儿子的头。这一摸，像他爹摸他那样。

一代摸一代。这一族，就这么传下去了。

林安看着他儿子跑远的背影，忽然想，他爹当年，也是这么看着他的。

如今换了他，看着他的儿子。

这一看，就看一辈子。

"小系。"

【在。】

"你说，"林安说，"往后的人，会记得我爹吗？"

【会。】小系说，【记在账上，记在碑上，记在人心里。】

"那就好。"林安说。

这一句"那就好"，跟他爹，一个音儿。

这一族人，一个路数。一个音儿。一颗心。

守着这一族，就是守着这一颗心。

这一颗心，从林北那儿起，到林安这儿，再到林守那儿，一代一代，传下去。

传到很久很久以后，这颗心，还在。

还在守。还在传。还在照着那句——别丢人。

这一句，就是林氏的族规。也是林氏的根。

传到很久很久以后。永不断。永不忘。永有人守。这是林氏的命。

"老守爷爷，"他说，"日头出来了。"

碑上，敲一下。

"你也看见了？"

敲一下。

"那就好。"林安说，"我陪您。天天陪。"

敲一下。

这一下，很轻。像从前，摸他爹的头那样。

"老守爷爷，"林安说，"我爹走了。往后，我陪您。"

敲一下。

"您别孤。"林安说，"您不孤了。"

敲一下。

这一下，比上一下，更轻。像一个人，点了点头，又低了低头。

林安站在碑前，看着那一轮日头。

他忽然懂了他爹那句"守下去"。

守下去，不是一个人守。是一代一代，接着守。

他爹守了八年，守到他来接。他守，守到他儿子来接。

一代接一代。这一族，就不散。这一门，就不丢。这一心，就不凉。

"老守爷爷，"林安说，"我记住了。"

碑上，敲了一下。

这一下，是"好"。

林安往回走。走了几步，又停下，回头看了一眼那块碑。

碑上那三个字——"林氏族"，金字发亮。

这三个字，往后，就是他的了。

他要守好。

守到他儿子来接。

守到很久很久以后。

他把这一件事，写在账上。备注：今日，我接了。往后，一代一代，守下去。

这一笔，是他这辈子，头一笔。

往后的账，都是他的了。

一笔一笔，他要记清。记清了，往后传给林守。林守再传给他的儿子。

一代一代，传下去。

传到很久很久以后，还有人翻这本账，还会看见那一句——别丢人。宁亏灵石不亏人。

还会照着做。

这一句，就是这一族人的根。

根在，族就不散。

写完，他把笔搁下，看了看门外。

门外，日头正亮。这一族人，各干各的。看门的，算账的，种地的，打铁的。

各守各的。各尽各的。

这一族，就稳了。

林安看着这一街的人，忽然想，他爹这一辈子，做的最对的一件，不是赚了钱，不是立了族。

是把这一族人，都守成了自己的人。

这一族人，不是雇来的。是处出来的。

处出来的人，才肯守。

"小系，"林安说，"你说，我怎么才能，也把他们，处成自己的人？"

【拿心换。】小系说，【你爹说过的。】

"拿心换。"林安说，"那我晓得了。"

【晓得了，】小系说，【就做。】

"做。"林安说，"一天一天，做。"

【这就对了。】小系说。

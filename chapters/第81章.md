# 第81章 千杯不醉丹：宗门比酒大会

转世丹的第一个顾客，是被小一从后屋"叫"醒的。

"主---人---后---屋---那---位---动---了---"

林北放下抹布往后屋走。那个一百二十岁的老者正坐在床沿上，盯着自己的手看。

"醒了？"

"醒了。"老者说，"饿。"

"灶上给你温着粥。"

老者捧着碗，呼噜呼噜喝了两碗，喝完把嘴一抹，忽然笑了。

"老板，我那灵根，松了。"

"松了？"

"卡了六十年的关口，松了。"老者说，"我那四灵根，现在是三灵根。"

林北点点头。转世丹，天赋提升一个等级。说明书上写的，一点没差。

"死这一回，什么滋味？"

"比睡一觉还舒坦。"老者说，"就是躺的地方硬了点，还有个小木头人，一晚上给我盖了六回被子。"

"是---我---铺---的---被---褥---"小一站在门口说。

"多谢小哥。"老者说。

"不---是---小---哥---是---店---里---的---人---偶---"

老者也不恼，下床活动了两下腿脚，从怀里摸出那袋找零，整整齐齐摆在桌上，起身告辞。

走到门口，他回头说："老板，你这药，我回去得跟老伙计们念叨念叨。"

"念叨的时候，别忘了说疼不疼、死没死。"林北说，"全说，才像真话。"

老者哈哈笑着走了。

林北看着他的背影，把碗收了。一个攒了三十年灵石的老人，为一个重新开始的机会，真敢死一次。

这世上肯花大价钱买药的人多，肯花一条命换天赋的人少。

比酒大会前两天，周明远来了。

"老板，"他探头进来，"有没有让人喝酒不醉的药？"

"有。"林北说，"千杯不醉丹，五块灵石一颗。"

"能喝多少？"

"千杯。"林北说，"字面意思。"

周明远掰着指头算了算："去年我三坛就倒，被笑了整整一年。"

"那你今年想喝几坛？"

"至少比赵大虎多。"周明远说，"他三十坛。"

"兄弟，你这不叫想赢，这叫想报仇。"林北把药瓶推过去，"不过都一样。吃一颗，保你站着喝到他躺下。"

"副作用呢？"

"有。"林北说。

"什么副作用？"

"你先吃，回头再说。"林北说，"现在讲了，你就不买了。"

"……你这话说得跟奸商似的。"

"长得像奸商的是我，卖真药的也是我。"林北说，"五块灵石，童叟无欺。"

周明远咬咬牙，买了两颗。"一颗备用。"

"聪明。"林北说，"记住，喝完第二天别练剑。"

"为什么？"

"到时候你就知道了。"

千杯不醉丹的名声，是从一场宗门比酒大会传开的。

青云宗每年秋天比酒，弟子之间拼酒量，赢的人得一坛陈年灵酒。

往年冠军都是赵大虎。他酒量惊人，一个人能喝三十坛不倒，人称"酒缸"。

今年来了个挑战者，叫周明远。就是之前喝真言水、当众把心事说秃噜的那个。

"周明远，你也来比酒？"赵大虎乐了，"你三坛就倒，忘了？"

"今年不一样。"周明远说。

"哪儿不一样？"

周明远从怀里掏出一颗药丸，当着二十多个师兄弟的面吞了下去。

"千杯不醉丹。"他说，"林氏杂货铺买的。"

"吹吧。"赵大虎一拍酒坛，"开始！"

裁判是陈长老。他抱着拂尘坐在上首，本想说两句场面话，坛子已经开了封。

一坛。两坛。三坛。周明远面不改色。

十坛。二十坛。三十坛。周明远还替旁边的人倒酒。

"他把酒倒袖子里了！"有人喊。

周明远把两只袖子撸到胳膊肘，袖口干干净净。他还打了个酒嗝，脸都没红。

赵大虎的脸色变了。

五十坛。六十坛。七十坛。

赵大虎出溜到桌子底下去了，嘴里还含含糊糊喊着"再来"。

周明远站着，把最后一坛酒放下。

全场安静了一息，然后炸了。

"他赢了！"

"那药真有这么神？"

"千杯不醉丹！林氏杂货铺！"

周明远抱起那坛陈年灵酒，没喝，先给师父敬了一碗。

酒香混着夜风飘了半场，闻着冲鼻子。弟子们划拳的划拳，抬人的抬赵大虎，一直闹到三更。

第二天一早，周明远来了。

扶着门框进来的。

"老板，"他脸色发白，"你这千杯不醉丹……"

"副作用来了？"林北问。

"来了。"周明远说，"昨天喝七十坛，一点感觉没有。今天早上，七十坛的后劲，一起上来了。"

"什么滋味？"

"脑袋里像有二十个人在敲钟。"周明远说，"我现在听见'酒'字就犯恶心。"

"那你别听。"林北说。

"你说得轻巧……持续多久？"

"三天。"林北说，"你喝了多少，就压多久。七十坛，三天，算你命好。"

周明远扶着柜台，半天没动。

"有没有解药？"

"解药没有。"林北说，"回春散有，两块灵石一瓶，能让你头疼得轻一点。"

"你这算不算捆绑销售？"

"这叫售后。"林北说，"你在我这买的药出了状况，我总得管到底。"

周明远掏了两块灵石，抱着药瓶走了。走到门口又回头："老板，明年比酒，我还来。"

"还吃？"

"吃。"周明远说，"冠军的酒，敬师父，值三天头疼。"

下午，赵大虎也来了。

"老板，"他把五块灵石拍在柜台上，"给我来一颗。"

"你也想明年赢回来？"

"不是。"赵大虎说，"我想知道，我是怎么输的。"

"他吃了千杯不醉丹。"林北说，"喝的时候不醉，第二天宿醉三天。"

"三天？"赵大虎愣了愣，"那昨天他抱着酒坛子乐什么？"

"乐他赢了。"林北说。

赵大虎站在那儿想了一会儿，把药收进怀里。

"这药我不在比酒的时候用。"

"为什么？"

"靠药赢的，不是真本事。"赵大虎说，"我赵大虎喝酒，喝的是量，不是命。"

林北看着他，觉得这汉子有点意思。

"兄弟，你这话我记住了。"

"记它干嘛？"

"以后有人嫌我的药是歪门邪道，我就把你这话学给他听。"林北说，"药是给人垫一脚的，路还得自己走。"

赵大虎咧嘴一笑，摆摆手走了。

晚上盘账。千杯不醉丹十五颗，回春散三瓶。

门口的风铃响了一声。

老周拎着一坛酒进来，把坛子往柜台上一放，坛底磕出一声闷响。

他没说话，眼睛越过林北的肩膀，落在那瓶千杯不醉丹上。

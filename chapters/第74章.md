# 第74章 缩地草鞋：穿上就跑，方向随缘

缩地草鞋的第一个顾客，是个被追杀的散修。

准确地说，是被三个人追杀的散修。

那天下午，一个浑身是血的年轻人冲进杂货铺，扑通一声跪在地上。

"老板！救命！"

林北吓了一跳。

"兄弟，你谁啊？"

"我叫陈三，散修。"年轻人说，"有人追杀我！"

"为什么追杀你？"

"因为我偷了他们的灵石。"陈三说。

林北挑了挑眉。

又是一个偷东西被追杀的。

"你偷了多少？"

"三十块。"陈三说，"但我不是故意偷的，我是借的。"

"借的？"

"对。"陈三说，"我跟他们借了三十块灵石，说好一个月还。但我没钱还，他们就要杀我。"

林北看着他。

"兄弟，借钱不还，被人追杀，这事你理亏。"

"我知道。"陈三说，"但我真的没钱。"

"那你跑到我这来干嘛？"

"我想买个能逃跑的东西。"陈三说。

逃跑。

林北想了想。

"缩地草鞋。"他说，"穿上之后，可以瞬移。"

"瞬移？"陈三的眼睛亮了，"能移多远？"

"十丈。"林北说，"每瞬移一次，参悟一丝空间法则。"

"副作用呢？"

"瞬移方向随机。"林北说，"你可能往前移，也可能往后移，也可能往左往右。"

"随机？"陈三愣住了，"那如果我往后移，不就跑到追兵面前了？"

"有可能。"林北说。

陈三的脸色变了。

"那这东西......能保命吗？"

"看运气。"林北说，"如果你运气好，往前移十丈，就能甩掉追兵。如果你运气不好......"

"运气不好怎样？"

"可能移到追兵面前，也可能移到悬崖边上。"林北说。

陈三沉默了。

门口传来脚步声。

追兵来了。

三个人，穿着黑色道袍，脸上带着杀气。

"陈三！你给我出来！"

陈三的脸色煞白。

"老板，我买。"

"十块灵石。"林北说。

陈三从怀里掏出灵石，数了十块放在柜台上。

林北递了一双草鞋过去。

陈三穿上草鞋，跑出店门。

追兵看见他，立刻追了上去。

陈三跑了几步，然后......瞬移了。

他的身影一闪，消失了。

然后出现在了......追兵的身后。

"在那。"

追兵转身，继续追。

陈三又跑了几步，又瞬移了。

这次出现在了......左边。

追兵又追了上去。

陈三又跑了几步，又瞬移了。

这次出现在了......右边。

追兵又追了上去。

陈三又跑了几步，又瞬移了。

这次出现在了......原地。

"......"

追兵愣住了。

陈三也愣住了。

"你......你瞬移回原地了？"

"我......我也不知道怎么回事。"

追兵扑上去，把陈三按在地上。

"跑。让你跑。"

陈三被按在地上，一脸绝望。

林北站在店门口，看着这一幕，摇了摇头。

缩地草鞋的副作用，就是这样。

瞬移方向随机。

你可能逃掉，也可能瞬移回原地。

看运气。

"系统，缩地草鞋的销售数据怎么样？"

【累计销售：1个。】

【顾客满意度：C级。】

【获得经验值：+10。】

C级满意度。

也是，谁会满意一双让自己瞬移回原地的草鞋呢？

但林北知道，这双草鞋的功效是真的。

瞬移十丈，参悟空间法则。

只是方向随机。

如果运气好，它就是逃命神器。

如果运气不好......

那就是送命神器。

"小一。"

"在---"

"帮我记一下，缩地草鞋的第一个顾客，满意度C级。"

"是---主---人---"

小一把这件事记在账本上。

林北坐在柜台后面，看着窗外的街道。

缩地草鞋，功效是真的。

但副作用也是真的。

这是他的商品的特点。

功效强，副作用也强。

买了会后悔，但下次还会买。

因为功效的诱惑，比副作用的恐惧更大。

林北看着货架上的草鞋，笑了。

这双草鞋，迟早会成为逃命的标配工具。

前提是，你的运气够好。

但林北没想到的是，缩地草鞋的故事，还没结束。

第二天，陈三又来了。

这次没有追兵。

"老板，"他走进店里，脸上带着兴奋的表情，"我要再买一双缩地草鞋。"

林北看了他一眼。

"你昨天不是被抓住了吗？"

"抓住了。"陈三说，"但他们打了我一顿之后，就放了。"

"放了？"

"对。"陈三说，"他们说，看我被瞬移回原地的样子太可怜了，不忍心再打我。"

林北："......"

"但我发现了一个秘密。"陈三说。

"什么秘密？"

"缩地草鞋的瞬移方向，虽然随机。"陈三说，"但如果你在瞬移的瞬间，心里想着一个方向，瞬移的方向就会偏向你想的方向。"

林北愣住了。

"真的？"

"真的。"陈三说，"我昨天被抓了之后，又试了几次。每次瞬移的时候，我心里想着'往前'，瞬移的方向就真的往前偏了一点。"

"偏了多少？"

"大概......一丈。"陈三说。

一丈。

不多，但确实是一个进步。

"所以你想再买一双？"

"对。"陈三说，"我要继续练。如果我能完全控制瞬移的方向，那这双草鞋就是真正的逃命神器。"

林北笑了。

"行。十块灵石。"

陈三掏出灵石，买了一双缩地草鞋，走了。

林北看着他离去的背影，心里想：

缩地草鞋的副作用，居然是可以克服的。

如果陈三说的是真的，那这双草鞋的价值，就比他想象的更高了。

瞬移十丈，参悟空间法则，方向可控。

这不就是......空间法则的入门修炼工具？

"系统，缩地草鞋的瞬移方向，真的可以控制吗？"

【可以。】

【但需要长期练习。】

【建议：顾客自行摸索。】

自行摸索。

林北笑了。

这系统的回答，永远都是这么简洁。

"小一。"

"在---"

"帮我更新一下缩地草鞋的价目表。"

"是---"

林北拿出纸笔，重新写了一张价目表：

```
缩地草鞋
功效：穿上后可瞬移十丈，参悟空间法则
售价：10灵石/双
副作用：瞬移方向随机（可通过练习控制）
适用人群：逃命、修炼空间法则
```

他把价目表贴在货架上，笑了。

缩地草鞋的价值，提升了。

从"逃命神器"变成了"空间法则入门修炼工具"。

这双草鞋，迟早会成为修士们的必备装备。

前提是，你的运气够好。

或者，你的练习够多。

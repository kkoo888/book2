# 第67章 真言水：我师妹问我她好看吗

真言水的名声，是从一场宗门相亲开始的。

青云宗有个内门弟子，叫周明远，炼气九层，长得一表人才。

他师妹对他有意思，但他一直不确定。

那天，他来杂货铺买筋骨淬炼丹，看见货架上摆着真言水。

"老板，这真言水是什么？"

"喝了之后，一个时辰内悟性翻倍。"林北说，"修炼效率暴涨。"

"副作用呢？"

"期间只能说真话。"

周明远的眼睛亮了。

"只能说真话？"

"对。"林北说，"喝了之后，不管别人问什么，你都会如实回答。"

周明远想了想。

"那如果我师妹问我她好看吗......"

"你会如实回答。"林北说。

"如果她确实好看呢？"

"那你会说她好看。"

"如果她不好看呢？"

"那你会说她不好看。"林北说，"但你既然想问这个问题，说明你觉得她好看，对吧？"

周明远的脸红了。

"我......我只是想确认一下。"

"确认什么？"

"确认她对我有没有意思。"周明远说，"如果她喝了真言水，我问她对我有没有感觉，她会如实回答吗？"

林北明白了。

这小子想用真言水来试探师妹的心意。

"理论上可以。"林北说，"但你得让她也喝。"

"那我买两瓶。"

"八块灵石一瓶，两瓶十六块。"

周明远掏出灵石，买了两瓶真言水，欢天喜地地走了。

三天后，他回来了。

脸色很复杂。

"老板......"

"怎么了？"林北问，"你师妹怎么说？"

"她说了。"周明远说，"她确实对我有感觉。"

"那不是好事吗？"

"是好事。"周明远说，"但她在喝完真言水之后，还说了一些......不该说的话。"

"什么话？"

"她问我：'你上次借我的灵石，什么时候还？'"

林北："......"

"我当时正在喝真言水，所以......"

"所以你如实回答了？"

"对。"周明远说，"我说：'我忘了。'"

"然后呢？"

"然后她又问：'你上次说你修炼很忙，其实是在酒馆喝酒，对吧？'"

"你又如实回答了？"

"对。"周明远说，"我说：'是的。'"

林北忍住笑。

"还有呢？"

"还有......"周明远的表情更复杂了，"她问我：'你觉得我师姐好看吗？'"

"你怎么说的？"

"我说......"周明远的声音越来越小，"我说：'比你好看一点。'"

林北："......"

"然后她就生气了。"周明远说，"再也不理我了。"

林北看着他，不知道该说什么。

真言水的副作用，就是这样。

它会让你说真话。

但真话，不一定好听。

"兄弟，"林北说，"你下次喝真言水之前，先想想哪些问题不能回答。"

"我想了啊。"周明远说，"但我没想到她会问那些问题。"

"所以你得提前准备好。"林北说，"比如，她问你师姐好不好看，你就说'我没注意'。"

"但真言水不允许说谎啊。"

"那你就说'我不方便回答'。"林北说，"真言水只让说真话，没说不能拒绝回答。"

周明远想了想，觉得有道理。

"好。"他说，"那我再买两瓶。"

"又买？"

"这次我要准备好了再喝。"周明远说，"我要提前想好所有可能的问题，然后准备好答案。"

林北笑了。

"行。十六块灵石。"

周明远掏出灵石，买了两瓶真言水，又欢天喜地地走了。

林北看着他离去的背影，摇了摇头。

真言水，真的是修仙界最危险的商品之一。

它能让你说真话。

但真话，往往是伤人的。

"系统，真言水的销售数据怎么样？"

【累计销售：23瓶。】

【顾客满意度：B级×15，A级×8。】

【获得经验值：+184。】

满意度B级居多。

也是，谁愿意被逼着说真话呢？

但功效是真的好——悟性翻倍，修炼效率暴涨。

这就是真言水的矛盾之处。

功效强，副作用也强。

买了会后悔，但下次还会买。

因为修炼的诱惑，比说真话的恐惧更大。

林北看着货架上的真言水，笑了。

这东西，迟早会成为宗门相亲的标配工具。

到时候，他的生意就更好了。

但林北没想到的是，真言水的名声，比他想象的传得更快。

第二天，来了三个青云宗的弟子。

"老板，我们要买真言水。"

"三瓶？"林北问。

"六瓶。"领头的弟子说，"我们三个，每人两瓶。"

"你们也要试探师妹？"

"不是。"弟子说，"我们要用它来修炼。"

"修炼？"

"对。"弟子说，"喝了真言水之后，悟性翻倍。我们正好要突破瓶颈，需要提升悟性。"

林北明白了。

真言水的价值，不只是说真话。

它的核心价值，是提升悟性。

说真话只是副作用。

真正的功效，是修炼。

"行。六瓶，四十八灵石。"

弟子掏出灵石，买了六瓶真言水，走了。

林北看着他们离去的背影，心里想：

真言水的定位，需要调整。

以前，他一直把"说真话"当作主要卖点。

但现在看来，"提升悟性"才是真正的卖点。

说真话只是附带的。

"系统，真言水的核心功效是什么？"

【一个时辰内悟性翻倍，修炼效率暴涨。】

【副作用：期间只能说真话。】

悟性翻倍。

这才是真言水的核心价值。

林北看着货架上的真言水，心里盘算着。

以后推销的时候，要强调"提升悟性"，而不是"说真话"。

这样，真言水的销量，至少能翻一倍。

"小一。"

"在---"

"帮我更新一下真言水的价目表。"

"是---"

林北拿出纸笔，重新写了一张价目表：

```
真言水
功效：一个时辰内悟性翻倍，修炼效率暴涨
售价：8灵石/瓶
副作用：期间只能说真话
适用人群：修炼瓶颈期、备考、相亲（慎用）
```

他把价目表贴在货架上，笑了。

定位调整完毕。

接下来，就看效果了。

窗外的风吹进来，带着一丝凉意。

林北看着窗外的夜色，笑了。

他的杂货铺，每一样商品都有自己的故事。

筋骨淬炼丹的故事，是"吃了浑身疼，但真有用"。

通络排毒散的故事，是"放了三个时辰的屁，但排毒效果是真的好"。

驻颜焕颜泥的故事，是"涂上变鬼，洗掉变仙"。

真言水的故事，是"说了不该说的话，但悟性真的翻倍了"。

每一个故事，都是一个口碑。

每一个口碑，都是一个传说。

每一个传说，都会吸引更多的人来买药。

这就是他的商业模式。

不靠广告，靠口碑。

不靠吆喝，靠故事。

不靠降价，靠品质。

林北笑了笑，关上门，走进后屋。

明天还有得忙。

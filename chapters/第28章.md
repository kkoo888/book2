# 第28章 退一赔十？先盘账

那天上午，店里的客人正多。

一个黑脸汉子挤开人群，一巴掌拍在柜台上，嗓门盖过了整条街："退一赔十。你们卖假药，吃坏了我的肚子。"

店里一静。

所有人的眼睛齐刷刷看过来。

林北抬起头，把算盘往边上挪了挪。

"兄弟，你先说说，买的什么？"

"筋骨淬炼丹。"汉子举起一个空瓷瓶，在半空晃得哐哐响，"三块灵石一颗。我吃了之后，躺了三天三夜，爬都爬不起来。"

"躺了三天，那是正常反应。"

"放屁。"汉子又是一巴掌，"我兄弟吃了就没事。你这药，有真有假。今天你要是不赔，我就去城主府告你。"

围观的人开始嗡嗡地议论。

苏小鱼从货架后面跳出来，袖子都撸起来了："你胡说，我们的药颗颗一样。"

"小鱼。"林北按住她，"站后面去。"

"林北，他这是讹人。"

"我知道。"林北转回来，慢悠悠地问，"兄弟，你哪天买的？"

"初、初五。"

"上午下午？"

"下午。太阳快落山的时候。"

"买了几颗？"

"一颗。"

"付了多少？"

"三块。有整有缺的三块。"

汉子答得飞快，快得像背过。

林北点了点头，弯腰从柜台底下搬出一本厚厚的账册，往柜台上一放。账册砸在台面上，扬起一点灰。

"小一。"

小一从门口走过来，铁脚板踩在青砖上，咔，咔，咔。

"主---人---"

"初五，下午，太阳落山前后。"林北说，"你念。"

小一把账册翻到那一页，脑袋歪着，一个字一个字地往外蹦。

"十---月---初---五---下---午---末---时---二---刻---张---铁---匠---回---春---散---两---包---"

"接着念。"

"末---时---四---刻---无---名---客---人---清---心---丸---一---颗---"

"再往下。"

"酉---时---正---关---门---当---日---没---有---第---三---位---客---人---"

小一合上账册，抬起头。

"初---五---下---午---没---有---人---买---筋---骨---淬---炼---丹---"

店里炸开了锅。

"我记错了。"汉子的脸涨成猪肝色，"是初六。"

"初六全天大雨，我这店没开门。"林北说，"屋顶漏水，我修了一天。要不要叫张铁匠来作证？他那天还借了我两块瓦。"

"那、那是初四。"

"初四下午你也不在。"林北把账册往前推了推，"兄弟，你手里那个瓶子，是青瓷的。我这店的筋骨淬炼丹，从来只用粗陶罐。你那瓶子，是南边坊市杂货摊上三文钱一个的样式。"

他顿了顿。

"要不要我陪你去认认摊子？"

汉子的脸，由红转白，又由白转青。

他把瓶子往怀里一塞，扭头就往外挤。

"让让，让让。"

人群没让。

李婶端着糖葫芦架子堵在门口，絮絮叨叨："哎哟，这年头讹人的都讹到杂货铺来了。你吃坏了肚子？我看你嗓门倒挺好的，吼起来半条街都听得见……"

"让开。"汉子一急，抬手就要去推李婶。

手抬到一半，他整个人僵住了。

一股说不出的凉意从脚底板窜上天灵盖。他像是突然意识到自己站在一个不该撒野的地方，浑身的汗毛一根根立起来。那只手在半空抖了两下，硬是没推出去。

小二不知道什么时候站在了他身后。

两尺高的铁皮人偶，铜关节，红眼睛，一只手已经拎住了他的后领。

"放、放开。"

小二没放。它把人拎起来，转了个方向，稳稳地放到店门外的台阶上，还顺手帮他拍了拍衣服上的灰。

动作标准得像在搬一袋米。

"慢走。"林北说，"欢迎下次带证据来。"

汉子连滚带爬地跑了，跑出十几步，回头喊了一嗓子："你们等着。"

没人理他。

李婶先笑出了声，跟着满屋子的人都笑了。

"小一，继续收账。"

"主---人---今---天---的---账---比---昨---天---好---看---"

"嗯。"

苏小鱼还气鼓鼓的："就让他这么走了？便宜他了。"

"不便宜。"林北把账册合上，"他这一闹，比我在门口贴十张告示都管用。你看着吧。"

"你就这么肯定？"

"前世我们那行有个规矩，叫留痕。"林北说，"需求要留痕，改动要留痕，谁说了什么都要留痕。不然出了事，一百张嘴都说不清。"

"前世？"

"上辈子。"林北说，"我给人干活的时候，吃过没系统的亏。从那以后，我连客人进门先迈哪只脚都想记下来。"

苏小鱼听得直乐："那你这簿子，比城主府的税册还全。"

"税册收钱，账册保命。"

果然。

当天下午，店里的客人比平时多了一半。进来的人都要问一句，听说上午有人来讹你，被你一本账册问跑了？

"不是问跑了。"林北说，"是账册跑赢了他。"

张铁匠挤在人群里，朝这边竖了个大拇指："林北，清白这东西，说一百句不如翻一页。你这账，记得清楚。"

"张叔，夸我可以，买药请排队。"

苏小鱼在旁边收钱收到手软，还不忘回头瞪一眼门外："那人要是再敢来，我把他拎出去。"

"不用你拎。"林北说，"小二拎过了。它现在拎人的手法，比你卖货的手法还熟。"

小二听到有人叫它，脑袋转过来，红眼睛闪了两下。

"抬---头---挺---胸---搬---货---不---累---"

"谁教你的？"

"小---一---哥---哥---"

小一站在柜台后面，歪着脑袋，一动不动，像个没事人。

傍晚打烊的时候，老周端着酒碗晃进来，往柜台上一靠。

"白天那主儿，我见过。"

"在哪见的？"

"前天后晌，在东头丹药铺的后门转悠。"老周灌了一口酒，慢悠悠地，"转悠了半个时辰，才从后门进去。"

东头。

丹药铺。

王德发的地界。

林北擦柜台的手停了一下，又继续擦。

"谢了，老周。"

"谢什么，我就是顺嘴。"老周晃晃悠悠往外走，走到门口又回头，"酒给我留一坛，下个月的酒钱，我先赊着。"

"老周，你上个月的还没结。"

"所以我这不说了嘛。下个月的，先赊着。"

他笑着走了。

林北把抹布搭在肩上，翻到簿子最后一页，用炭笔轻轻画了个问号。

讹人的、指使的、看热闹的，一笔一笔，都在这本子里。

这笔账，还没完。

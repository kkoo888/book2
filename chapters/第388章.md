# 第388章 渡劫

雷云，压顶。天元城的天，全黑了。乌云翻滚，电蛇乱窜。这天威，吓人得很。仿佛老天，都要灭了他。可他偏不服输。

第一道天雷，轰然落下。那雷，粗如水缸，带着毁天灭地的威势，朝林北劈来。这一下，能劈死一头巨兽。寻常修士，挨上必死。可林北，偏偏不怕。他就是要跟天斗一斗。

林北没躲。他张开双臂，硬接了这一下。他要借这天雷，淬炼自己。

轰。他浑身一震，衣衫尽裂。那雷，劈得他皮开肉绽。可他丹田里的气，却在这天雷的淬炼下，猛地一涨。天雷，是最好的淬炼。林北懂这个道理。他做买卖，也讲究个险中求胜。

渡劫，说白了，就是要挨雷劈。挨过去，就是海阔天空。挨不过去，就是灰飞烟灭。

"林北！"苏小鱼喊，"你疯了。"

"没疯。"林北说，"这是我的机缘。护着我。"

"好。"苏小鱼说，"我护着你。"

苏小鱼明白了。她飞到林北身边，寒气外放，把靠近的魔军，全冻成了冰。她要给林北护法，让他安心渡劫。她知道，这是林北的紧要关头。她得护好他。哪怕拼了自己的命。她也在所不惜。

杨无极看出了端倪。他是老江湖，一眼就看穿了。这小子，想借天雷突破。好大的胆子。他活了几百年，从没见过这么拼命的人。

"他要突破渡劫。"他说，"不能让他成。"

他一挥手，朝林北猛攻。可苏小鱼，死死挡在林北身前。她一步不退。硬是把杨无极，挡在了外头。杨无极攻了好几回，都没攻进来。气得他直咬牙，却又无可奈何。她九阴玄体完全觉醒，寒气逼人。杨无极一时，竟攻不进来。这寒气，太毒了。杨无极都不敢硬接。

第二道天雷，落了下来。比第一道，更猛。

林北又硬接。轰。他嘴角渗血，可身子，站得笔直。他不能倒。他还有一大家子人要护。小鱼、老周，还有那么多兄弟。他们都在看着他。他答应过，要护着这些人。说到做到。这是他做人的根本。

"来吧。"他说，"我不怕。"

他咬紧了牙关。

第三道、第四道、第五道。一道比一道猛。林北浑身是血，可他始终站着。他像一座山，稳稳地立着。任凭天雷轰击。每挨一道雷，他丹田里的气，就涨一分。他在变强。每一雷，都是一次蜕变。他的肉身，越来越强。像一块百炼精钢。

城墙下，老周带着众人，拼命挡住魔军。他们不能让魔军，打扰林北渡劫。这一仗，他们得守住。

"护住林老板！"老周喊，"让他安心渡劫。"

"是。"众人喊。

赵铁匠抡着大锤，一锤一个。他虽是凡人，可这股子力气，不输修士。打得魔军哭爹喊娘。这一身力气，没白练。平日里打铁，练出来的。王财主虽不会武，也带着家丁，守在城墙根。白老头把丹药，一颗一颗，喂给受伤的人。他的丹药，救了不少人。他自己，都舍不得吃。这回，全拿出来了。一点没留。

"林掌柜，你一定要成。"众人在心里喊。

第六道天雷，轰然落下。这一道，粗如水桶，比前五道加起来，都猛。天地，都暗了。

林北大吼一声，迎了上去。

轰。他被劈得跪倒在地。浑身焦黑，像一截枯木。他从没这么惨过。可他没喊一声疼。他咬着牙，硬撑着。心里只有一个念头，成。

"林北！"苏小鱼急了。

"别过来。"林北咬着牙，慢慢站起来，"我，还没完。"

"你都这样了。"苏小鱼说，"还硬撑什么。你不要命了。你要是死了，我怎么办。你想想清楚。"

他心里默念。这几年，从一间杂货铺，到如今。他不是一个人在扛。有小鱼，有老周，有那么多信他的人。他不能倒。

那股气，在他丹田里，翻江倒海。越来越盛，越来越猛。像一头要挣脱牢笼的野兽。

第七道天雷，落了下来。

这一道，是最后一道。也是最猛的一道。那天雷，粗如大缸，带着天威，直劈林北。

林北迎上去，把全身的气，聚在头顶。他拼了。这一下，赌上了一切。成败，在此一举。他没有退路。只能往前。

轰。

一声巨响，天地变色。那天雷，劈在林北身上，把他整个人，都埋在了雷光里。

雷光散去。

林北站在那儿。他浑身焦黑，衣衫褴褛。可他的气势，变了。一股深不可测的威压，从他身上，朝四面八方，席卷开去。

渡劫期。

他渡过天雷，突破了渡劫期。七道天雷，全挨过去了。他成功了。他做到了。从今天起，他就是渡劫期了。这世上，又多了一个顶尖高手。天下格局，就此改写。

"成了。"他说，"我，渡劫了。"

他声音沙哑，可底气十足。渡劫期的气势，压得人喘不过气。连杨无极，都变了脸色。这气势，太强了。强得让人窒息。

那声音，不大，却传遍了整个天元城。所有人都听见了。渡劫期，那是传说中的境界。

"渡劫了！林掌柜渡劫了。"

"天啊，渡劫期。这是什么概念。"

"太厉害了。"众人说。

城墙上，一片欢腾。众人欢呼雀跃。

苏小鱼飞到林北身边，眼泪都下来了。

"你这个傻子。以后别这么拼命了。"她说，"吓死我了。"

"我没事。"林北笑了，"渡劫成功了。"

"成功了就好。"苏小鱼说，"你吓死我了。我以为你撑不过去。你这个傻子。"

他转身，看向杨无极。此刻的他，是渡劫期。杨无极，不过是化神巅峰。这差距，拉开了。

"杨无极，"他说，"我说过，今日，你赢不了。"

杨无极的脸，白了。他没想到，林北竟在战场上，突破了渡劫期。这下，局势逆转了。

"哼。"他说，"就算你渡劫了，也不过刚突破。我修炼几百年，未必怕你。"

"怕不怕，试试就知道。"林北说。

"那试试。"林北说，"看看谁怕谁。我倒要领教领教。你这渡劫期，有几分本事。我倒要看看。"

他抬手，一掌，朝杨无极拍去。这一掌，石破天惊。震得脚下的地，都在抖。那一掌，带着渡劫期的威压，排山倒海。这一掌，凝聚了他全部的力。毫不留情。这一掌，带着他的怒火。这些年积攒的火气，全在这一掌。

杨无极硬接。轰。他被震得倒退数步，嘴角渗血。

渡劫期，果然不凡。

这一战，胜负，已然逆转。攻守，易势了。如今，轮到林北占上风。杨无极，节节败退。他从没这么狼狈过。

## 写作规范速记（详见 framework.md）

- **字数**：每章纯正文 2,300-2,500 字（±50）
- **标题**：第X章 + 标题，≤15字，钩子式，全书不重复
- **系统黑箱**（最高优先级）：永不解释系统/杂货铺的来历与目的
- **店内无敌**：进店即压制到炼气期，敌意触发"大恐怖"，绝对不可破
- **节奏**：搞笑:打斗:剧情 ≈ 7:1:2；每章≥2笑点、≥1深意、≥1金句
- **去AI味**：禁词清单 + 高频词限额（framework 14章）
- **数据**：整数、对照 framework 13 章数据表（灵石/经验/境界）
